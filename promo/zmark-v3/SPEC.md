修订：r1，2026-11-20。状态：规划完成，待用户确认后开工。

已定：故事线 A；简体中文人声旁白，用 HyperFrames 内置 Kokoro 本地 TTS `zf_xiaobei` 生成；时长 60–75 秒，先做中文版；3D 只用于生成内容。

## 素材与真实性

- 截图或录屏：以 0.2.12 本机安装版为准，录制新建草稿、分屏同步滚动、Mermaid 渲染、灯箱、大纲跳转、首次保存和自动保存。录制使用专用演示 Workspace Root，不出现个人文件。
- 演示文稿 `release.md` 写入工程 `assets/`，Mermaid 源同时由 `zmark_core::mermaid::render_to_svg_themed` 导出 SVG，保证预览与 3D 节点文字一致。
- 夜色书桌与时钟是故事场景，不冒充产品界面；所有快捷键以 README 快捷键表为准。
- 音乐：沿用 zmark-v2 的 CC BY 曲目会与上期雷同，计划从免版税曲库另选一首并写入 `CREDITS.md`；若 HeyGen 曲库不可用，就去 incompetech 选择同类 CC BY 曲目。

## 制作步骤

1. 复制 zmark-v2 的字体、图标和调色板，新建 `promo/zmark-v3/` HyperFrames 工程，每个镜头一个 sub-composition。
2. 运行 `hyperframes tts` 生成旁白，并运行 `transcribe` 取得时间戳，按锚词确定根时间轴的总时长。
3. 用录屏素材重建界面状态，再接入 3D 开场、Mermaid 俯冲和片尾这三段 Three.js 场景。
4. 运行 `hyperframes check`、`snapshot --review`，然后写 `REVIEW.md`；在预览中给你验收，通过后才渲染交付。

## QA 清单

- 第 0 帧不是黑屏，能看到 `22:00` 与 3D `#`。
- 第 10.5、35.0、44.0、62.5 秒接缝前后各抽 3 帧，3D 与真实界面衔接时文字不跳动、不被遮挡。
- 每个快捷键提示与当帧界面状态一致；`⌘S` 镜头中草稿取消/保存语义与 0.2.12 行为一致。
- 3D 最重的一帧（俯冲穿过节点）单帧绘制时间低于 250 ms。
- 旁白和画面文字没有逐字重复；字幕区在 80% 标题安全框内。
- 成片 `hyperframes audio --json`：旁白存在，−14 LUFS 左右，真峰值 ≤ −1 dBTP。报告注明“测量所得，未经人耳试听”。

## 自查记录（r1，非独立审查）

按项目约定由当前代理自查，结论由用户确认。

- 假设：Kokoro 中文发音能读对 “ZMark”“Markdown”“Mermaid”。风险：英文词可能读错。处理：先生成 10 秒样音，必要时改写为音译或换英文声线念产品名。
- 假设：片中只展示 0.2.12 已有功能。已核对 README 快捷键表、草稿首次保存行为和 Mermaid 本机渲染。
