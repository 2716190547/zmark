# 审片记录

r3 优化版，2026-11-24。按项目约定由当前代理自查，不是独立审查。

## 本轮改动（对应用户反馈）

- 开头：第 0 帧就是满屏的 3D Markdown 符号，大 `#` 在 1.81 s 砸进空白文稿，文稿窗口随撞击抖动。
- 旁白：去掉。每个镜头一句短标题，逐字落下后静止；强调词用图标的红橙渐变。
- 配乐：换成《EDM Detection Mode》，build 垫开场，drop 落在 14.0 s 的亮相，53.375 s 的最后一记重拍落在图标合拢。
- 结尾 3D：页面碎成全片出现过的元素（符号、流程图节点、版本号、平台名、快捷键），炸开后旋入中心，两半 Z 在重拍上合拢并弹一下，再滑到字标旁。
- 颜色：3D 改用中性色调映射、影棚环境反射和清漆材质，颜色取自图标渐变；去掉开场颗粒和工作台网格，开场改为 `#0F1117`，工作台改为暖白 `#F4F2EE`。

## 已测量

- `hyperframes check`：0 个错误。
- `hyperframes snapshot --review` 和逐段抽帧：开场 16 帧、中段 12 帧、碎片汇聚 3 组各 6–16 帧。
- 成片 `renders/ZMark-Release-Night-1440p60.mp4`：2560×1440、H.264、60 fps、3528 帧，48 kHz 立体声 AAC，58.800 s；FFmpeg 全片解码通过；−14.1 LUFS，峰值 −1.2 dBFS。从 MP4 抽查 16 帧。
- 音乐重拍与画面对位（成片音频 0.1 s 窗口）：1.8 s 撞击、14.0 s drop、32.7 s 进 3D、51.5 s 拼接点、53.4 s 合拢都是局部峰值。
- 渲染耗时 75 秒（本机 GPU）。
