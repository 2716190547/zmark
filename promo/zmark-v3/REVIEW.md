# 审片记录

r2 制作版，2026-11-24。按项目约定由当前代理自查，不是独立审查。

## 已测量

- `hyperframes check`：0 个错误。保留的警告见下文。
- `hyperframes snapshot --review`：12 张节拍帧、5 个接缝、360 px 手机版。另逐帧比对了平面灯箱和 3D 场景交接的 43.05 / 43.08 s：节点位置、字号、箭头和纸面圆角一致。
- 成片 `renders/ZMark-Release-Night-1440p60.mp4`：2560×1440、H.264、60 fps、4320 帧，48 kHz 立体声 AAC，72.000 s；FFmpeg 全片解码通过；−14.0 LUFS，峰值 −1.5 dBFS。从 MP4 抽查 16 帧，覆盖每一幕和片尾。1080p 版本由 1440p 用 Lanczos 缩出。
- 渲染耗时 67 秒（本机 GPU，10 个 worker），三段 3D 没有拖慢渲染。

## 没人检查过

- **旁白和混音都没有人耳试听**，只测了响度和静音位置。Kokoro 对 “Zee Mark”、“Markdown”、“Mermaid”、“Command N” 的发音需要你听一遍确认。
- 音效是合成的，节奏按画面动作计算，没有逐个对过听感。

## 创作取舍

- 故事线 A《今晚要发版》，另两条（《一份 Markdown 的旅行》《Markdown 之城》）留在 STORYLINES.md。
- 本机没有录屏权限，ZMark 界面按源码布局和主题色重建，与上期做法相同。保存面板是简化的 macOS 系统存储面板。
- 3D 只用在生成内容上：开场的 `#`、立起的流程图节点、片尾图标。ZMark 窗口始终正视。
- 配乐在 14.5 s（“打开 ZMark”）进入强拍，流程图渲染后进入主段。
- 时长 72 秒，比规格里的 68 秒长，按旁白实际时长定。

## 最弱的镜头

- 14.4–15.6 s 的亮相：名字从夜色里出现得快，转场是淡入淡出。时间够的话，可以让编辑器窗口直接变形成 ZMark 窗口。
- 3D 俯冲（41.3–42.5 s）中节点侧面颜色偏深，是故意保留的立体感。

## 保留的警告

- `text_below_floor`：Drawer、工具栏标题和大纲文字沿用应用实际字号（14–18 px）。放大会和真实界面不一致。
- `line_unread`：开场滚动的原文本来就是“看不清”的那一拍；Mermaid 代码和预览滚动中的条目只需要看出在变化。
- `contrast_aa_failure`：Drawer 分组标题和存储面板的灰字沿用系统配色。
