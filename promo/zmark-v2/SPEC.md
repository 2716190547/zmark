# 《光速成稿》分镜

全片 35 秒，共 2100 帧。16:9，60 fps。短片用浅灰工作台、石墨暗场和琥珀橙焦点组织视线。景别由光标、文档和图表的实际位置衔接。中文文案无旁白。

| 时间 | 起始帧 | 画面与动作 |
| --- | ---: | --- |
| 0.00–4.00 | 0 | 输入 `# ZMark`，在 1.50 秒按 `⌘2`，光标拉长成两栏分隔线 |
| 4.00–12.00 | 240 | 源码和预览在 4.00、8.00 秒沿共同段落锚点滚动，停在发布流程 |
| 12.00–20.00 | 720 | Mermaid 卡片放大为暗场灯箱，16.00 秒起推进到 300%，随后回到原文 |
| 20.00–26.00 | 1200 | 打开文件树，切换大纲，点选「发布流程」并带动两栏定位 |
| 26.00–31.00 | 1560 | 工作台固定位置，26.50 秒起每 0.50 秒切换一个精选主题 |
| 31.00–35.00 | 1860 | ZMark 图标、口号、支持平台和 GitHub 地址 |

分屏使用 0.70 秒 `expo.out`，同步滚动分别用 0.92 和 0.95 秒 `power2.inOut`；灯箱入场 0.72 秒，缩放 0.80–0.96 秒。每次主题切换以 0.15 秒入场和 0.19 秒退出的色潮承接。交付使用渲染器的画面运动模糊。

音乐实测节拍约 120 BPM，前移 12 ms 对齐拍网。25.70–26.43 秒下压音乐，为七次主题切换留出首拍落点。按键、移动、切换和片尾音效用同一时间轴混入，母带目标 −14 LUFS。
