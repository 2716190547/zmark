# ZMark 0.2.11

2026-11-20

本版带来可自定义快捷键体验升级、内置矢量 SVG 欢迎页、正文 `[toc]` 可点击目录、`<br>` 换行与表格自适应列宽优化，包含 macOS（Apple Silicon）、Windows x86_64 和 Linux x86_64 构建。

## 快捷键自定义与侧栏大纲

- 新增文件夹与文档大纲侧栏一键互切快捷键（`Cmd+Shift+O` / `Ctrl+Shift+O`）。
- 升级「设置 → 快捷键」界面：为 17 项受管快捷键增加可编辑标识（悬停高亮、铅笔图标与 Tooltip 提示、已自定义徽标、`Backspace` 清空与 `Esc` 取消），统一录制与自定义选中态为系统级中性选色。
- 修复 `theme::init_components` 先注册 `CancelRename` 时导致后续受管快捷键绑定被跳过的初始化问题，并保持全局窗口快捷键在不同焦点场景下正常触发。

## 欢迎页、矢量 SVG 与排版增强

- 为初始欢迎示范文档赋予本地化标题（如 `欢迎使用 ZMark.md` / `Welcome to ZMark.md`）并保持干净（`Clean`）启动状态；支持在未保存文档中加载内置 `zmark-asset://` 纯矢量 SVG 插画，并支持点击进入 HiDPI 灯箱缩放。
- 更新 10 种语言欢迎文档，保留官方几何渐变 Logo 与圆角裁切风景明信片示例，移除繁琐的多步新手引导弹窗。
- 新增正文 `[toc]` / `[TOC]` / `[[toc]]` 独立段落解析：在预览中渲染为带层级缩进的可点击目录卡片，在导出 HTML 中生成带章节锚点的 `<nav class="zmark-toc">`。
- 支持轻量 HTML 换行标记 `<br>` / `<br/>`（独立段落作为纵向留白，行内转为换行并保留选区与 HTML `<br>` 导出）。
- 优化预览表格列宽分配：按各列内容视觉宽度计算 `flex_grow` 权重与紧凑最小列宽，减少窄列占位浪费并缓解长说明文本在单词中间生硬折行。

## 下载与限制

- macOS（Apple Silicon）：ZIP 或 DMG；Windows x86_64：安装程序；Linux x86_64：DEB 或 tar.gz。更新清单使用签名及 SHA-256 校验。
- macOS 应用使用 Ad-Hoc 签名，未做 Apple 公证；Windows 安装包未做发布者代码签名。
- 本地图片可预览，网络图片不会自动加载（欢迎页矢量图通过内置 `zmark-asset://` 资源加载；导出外部 HTML 时保留资源引用路径，Mermaid 块以代码导出）。
- Windows/Linux 包由 CI 构建和检查；本轮没有 Windows/Linux 桌面实机浏览验收。
