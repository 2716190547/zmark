# ZMark 0.2.9

2026-11-17

本版集中改进文件管理、文档内查找与媒体内存占用，包含 macOS（Apple Silicon）、Windows x86_64 和 Linux x86_64 构建。

## 文件与编辑

- 可将本地文件或文件夹拖入窗口，自动添加到侧栏；除 Markdown 外，可编辑常见代码、配置和纯文本文件，并按文件语言提供源码高亮。非 Markdown 文件使用源码模式。
- 侧栏支持 Shift 连选、macOS Cmd / Windows 和 Linux Ctrl 增减选择，右上角提供批量操作，Esc 退出多选。
- 区分“移除”和“删除”：移除只隐藏侧栏项目，可在 5 秒内撤销；删除将磁盘项目移到系统废纸篓。支持 Cmd+Option+Z / Ctrl+Alt+Z 撤销最近一次侧栏移除。
- 修复文件夹名称点击与展开动画、同级缩进、图标和选中背景的对齐，以及标题和侧栏重命名时的字体、宽度、光标与布局跳动。
- 默认调色板使用对比更清晰的暖灰控件选中色，其余调色板保留各自选中色；macOS 正文文本选择采用系统选区颜色。
- 保存通过临时文件原子替换，并检查磁盘冲突；常规保存、自动保存和草稿保存的错误会反馈到界面。

## 查找与预览

- 右上角新增文档内查找，可点击结果跳转；Cmd+F / Ctrl+F 打开，Enter / Shift+Enter、F3 / Shift+F3 切换匹配项，查找输入框内也可使用上下方向键。
- 改进 Mermaid 中文及跨行连接语法兼容，预览链接颜色跟随主题；图表后台生成，避免在界面线程同步生成媒体。
- 修正 Windows 灯箱滚轮缩放方向及不同滚轮增量的换算，缩放比例采用对称的指数计算。

## 内存与响应

- macOS 高亮改用 syntect 的 Oniguruma 后端，非 macOS 保留原有后端；源码解析状态在专用工作线程中复用。
- 文档内查找使用共享结果和稀疏索引，减少大量匹配项的常驻内存。
- 离屏图表、隐藏预览和文档切换时释放不再使用的纹理；预览图表按显示尺寸与屏幕缩放比例栅格化，并使用缓存预算。灯箱按需生成较高清晰度图像。
- macOS 大尺寸不透明 PNG/JPEG 使用系统 ImageIO 缩略解码，避免先分配完整尺寸像素；透明图片保留原有路径，保护透明度与颜色。
- 单行编辑局部更新，隐藏窗格延迟布局，代码块仅在点击复制时生成剪贴板字符串。
- 构建工具链统一为 Rust 1.100.0。

2026-11-17 本机有限浏览采样：恢复长文档分屏时 RSS 约 164.5 MiB，打开含图表文档并完成首张图绘制后约 173.4 MiB，后续空闲约 187.6 MiB。它们是特定场景的读数，并非严格的版本 A/B；长时间多图浏览、灯箱和瞬时峰值仍可能超过 200 MiB，偶发卡顿也仍需进一步测量。源码仓库的 `docs/plans/theme-selection-and-memory-audit.md` 记录了测量边界。

## 下载与限制

- macOS（Apple Silicon）：ZIP 或 DMG；Windows x86_64：安装程序；Linux x86_64：DEB 或 tar.gz。更新清单使用签名及 SHA-256 校验。
- macOS 应用使用 Ad-Hoc 签名，未做 Apple 公证；Windows 安装包未做发布者代码签名。
- 本地图片可预览，网络图片不会自动加载。HTML 导出保留图片路径，Mermaid 以代码导出。
- Windows/Linux 包由 CI 构建和检查；本轮没有 Windows/Linux 桌面实机浏览验收。
