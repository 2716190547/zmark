# ZMark 0.2.12

2026-11-24

本版修复草稿和欢迎页编辑后误触发自动保存而报错的问题，包含 macOS（Apple Silicon）、Windows x86_64 和 Linux x86_64 构建。

## 修复

- 修复编辑新草稿或欢迎页约 1 秒后出现 `Cannot save untitled document without destination path` 的问题。没有保存路径的草稿不再参与自动保存，内容、修改状态和撤销记录保留在编辑器中。
- 草稿首次手动保存（`Cmd+S` / `Ctrl+S`）时选择位置，取消后草稿保持不变；保存成功后，后续编辑照常自动保存。
- 已有路径文件的删除、权限和外部修改冲突仍会提示，不会被静默覆盖。

## 下载与限制

- macOS（Apple Silicon）：ZIP 或 DMG；Windows x86_64：安装程序；Linux x86_64：DEB 或 tar.gz。更新清单使用签名及 SHA-256 校验。
- macOS 应用使用 Ad-Hoc 签名，未做 Apple 公证；Windows 安装包未做发布者代码签名。
- 本地图片可预览，网络图片不会自动加载。
- Windows/Linux 包由 CI 构建和检查；本轮没有 Windows/Linux 桌面实机浏览验收。
