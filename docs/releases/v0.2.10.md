# ZMark 0.2.10

2026-11-18

本版改进工作区父目录管理、跨平台滚动条与分屏平滑同步体验，新增自定义主题配色支持并修复预览选区交互残留，包含 macOS（Apple Silicon）、Windows x86_64 和 Linux x86_64 构建。

## 工作区与自定义配色

- 侧栏添加或拖入包含既有子根目录的父目录时，自动吸收并整合子根目录（保留首项顺序、已展开子目录及扫描预算），保存失败时完整回滚；继续拒绝向已有父根目录内部重复添加子目录。
- 设置界面新增「自定义」配色方案：支持分别编辑浅色与深色两套 7 项界面核心颜色和 12 项语法高亮颜色，并支持从任意内置预设复制或恢复默认值；无效十六进制色值会被忽略，空自定义配置不写入默认 `config.toml`。

## 滚动条与分屏同步

- 改用跨平台 `gpui_component::scroll::Scrollbar`（`ScrollbarMode::Hover`），在 macOS、Windows 和 Linux 上统一支持悬停显现、滚动激活与闲置淡出；编辑器和预览右下角状态角标内移避让滚动条热区。
- 分屏（Split）模式下双侧均存在纵向溢出时，左右滚动条共享统一虚拟内容总高以保持滑块像素等长，按各自真实可滚区间等比映射，并在拖拽滑块期间冻结共享高度防止跳动。
- 分屏双向同步滚动改用连续视觉行定位与 1-based 小数源码行插值，配合 16ms 帧驱动平滑追赶减少跨大图/长代码块的卡顿跳闪；遵循 `reduce_motion` 无动画偏好，并在手动滚轮、拖拽、大纲跳转或切换视图时立即停止追赶。

## 预览交互修复

- 修复预览区在快速点击、窗外释放鼠标或 Esc 关闭灯箱后未收到左键抬起事件而继续拖拽选区的问题。
- 为横向滚动表格、Mermaid 容器与代码块启用滚动轴限制，并在预览图片与灯箱触发按钮上阻止事件向正文选区冒泡。

## 下载与限制

- macOS（Apple Silicon）：ZIP 或 DMG；Windows x86_64：安装程序；Linux x86_64：DEB 或 tar.gz。更新清单使用签名及 SHA-256 校验。
- macOS 应用使用 Ad-Hoc 签名，未做 Apple 公证；Windows 安装包未做发布者代码签名。
- 本地图片可预览，网络图片不会自动加载。HTML 导出保留图片路径，Mermaid 以代码导出。
- Windows/Linux 包由 CI 构建和检查；本轮没有 Windows/Linux 桌面实机浏览验收。
