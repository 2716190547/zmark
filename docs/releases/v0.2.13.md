# ZMark 0.2.13

2026-11-24

从本版起，ZMark 的安装包和自动更新统一发布在源码仓库 [`2716190547/zmark` 的 Releases](https://github.com/2716190547/zmark/releases)。本版包含 macOS（Apple Silicon）、Windows x86_64 和 Linux x86_64 构建。

## 变更

- 应用内自动更新改为从 `github.com/2716190547/zmark/releases` 获取签名更新清单和安装包；Gitee 国内镜像地址不变。
- 「设置 → 关于」和 10 种语言欢迎页中的发布页链接改为源码仓库。
- 原发行仓库 `zmark-releases` 将在本版同步发布后归档，v0.2.12 及更早版本仍可从中下载。0.2.12 及更早的客户端会从旧仓库收到本次更新，安装后改用新地址。

## 下载与限制

- macOS（Apple Silicon）：ZIP 或 DMG；Windows x86_64：安装程序；Linux x86_64：DEB 或 tar.gz。更新清单使用签名及 SHA-256 校验。
- macOS 应用使用 Ad-Hoc 签名，未做 Apple 公证；Windows 安装包未做发布者代码签名。
- 未升级到 0.2.13 的客户端在旧仓库归档后不再收到更新提示，需要手动下载新版本。
- Windows/Linux 包由 CI 构建和检查；本轮没有 Windows/Linux 桌面实机浏览验收。
