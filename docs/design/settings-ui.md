# 设置窗口设计规范

2026-11-27 制定。适用于 `crates/zmark_app/src/views/settings.rs`。尺寸常量在该文件的 `tokens` 模块，颜色角色在 `SettingsColors`。新增或修改设置项时只用下面的组件，不要手写尺寸、圆角或透明度。

## 原则

- **一层容器。** 卡片只有底色，没有描边。卡片里的控件也只有底色。不要出现「卡片描边 → 控件描边 → 选中描边」这样一层套一层。
- **描边只表达状态。** 只有两处允许描边：选中的调色板卡片（2px `accent`），以及正在录制的快捷键键帽（1px `accent`）。未选中的调色板卡片保留 2px 透明边，选中时尺寸不跳动。
- **对齐一条线。** 分区标题、卡片里的行文字、内容区左边缘对齐。卡片左右内边距和行文字缩进都是 12px。

## 尺寸

| 名称 | 值 | 用途 |
|---|---|---|
| `CONTROL_H` | 28px | 按钮、分段控件、键帽的高度 |
| `CONTROL_PX` | 12px | 按钮左右内边距 |
| `KEYCAP_MIN_W` | 88px | 快捷键键帽最小宽度，右边缘对齐 |
| `RADIUS` | 6px | 按钮、分段轨道、键帽、列表项 |
| `RADIUS_INNER` | 4px | 分段滑块（轨道圆角 6 − 内缩 2） |
| `RADIUS_CARD` | 8px | 设置卡片、调色板卡片、自定义主题编辑区 |
| `TRACK_INSET` | 2px | 分段轨道与滑块的间距 |
| `CARD_PX` | 12px | 卡片内边距，横向和纵向共用 |
| `ROW_PY` | 12px | 设置行上下内边距，等于 `CARD_PX`，控件到卡片上边和右边距离相同 |
| `TEXT_TITLE` | 20px 半粗 | 页面标题 |
| `TITLE_GAP` | 6px | 分区标题到卡片 |
| `SECTION_GAP` | 20px | 分区之间 |
| 内容区内边距 | 24px | 四边相同 |

按钮高度固定，不用上下内边距撑高，所以左右和上下的留白比例在所有按钮上一致。

## 字号

| 名称 | 值 | 用途 |
|---|---|---|
| `TEXT_LABEL` | 13px，常规 | 行标题、导航项、语言名 |
| `TEXT_BODY` | 12px | 行说明、按钮文字、分区标题（中等字重，灰色） |
| `TEXT_SMALL` | 11px | 「已自定义」等附注 |

层次靠「标题 13px 深色 / 说明 12px 灰色」区分，不靠加粗。

## 颜色角色

| 角色 | 取值 | 用途 |
|---|---|---|
| `card_bg` | `text_primary` 3.5% | 卡片底色 |
| `hairline` | `text_primary` 8% | 卡片内行分隔线 |
| `control_bg` | `text_primary` 6% | 次要按钮、键帽静止态 |
| `control_hover_bg` | `text_primary` 10% | 次要按钮、键帽悬停态 |
| `control_selection_bg` | 主题现有 token | 导航选中、已自定义键帽、冲突提示 |
| `segmented_*` | 主题现有 token | 分段轨道与滑块；滑块用阴影抬起，不加描边 |
| `accent` | 主题强调色 | 开关打开、选中调色板、录制中键帽、单选列表的勾 |

所有颜色都从当前主题推导，所以 8 套调色板和明暗模式自动适配。

## 组件

| 组件 | 函数 | 说明 |
|---|---|---|
| 分区 | `render_section` | 可选标题 + 一个内容块 |
| 设置卡片 | `render_setting_group` | 分区 + 多行，行间细线 |
| 设置行 | `render_setting_row` | 左标题/说明，右控件 |
| 次要按钮 | `render_secondary_button` | 填充、无描边、28px 高 |
| 文字按钮 | `render_text_button` | 低强调操作，如重置、取消 |
| 分段控件 | `render_segmented` + `render_segment` | 整行宽，28px 高 |
| 开关 | `render_ios_toggle` | 36×20 |
| 说明文字 | `render_help_text` | 分区下的辅助说明 |
| 单选列表 | 语言页 | 一张卡片，行高 40px，选中项右侧 `accent` 勾，不用底色块 |

## 页面结构

- 每页顶部有 20px 页面标题，与导航项同名；关于页保留标题占位但不显示文字，各页内容起始高度一致。页面内的分区标题不再重复页面名称。
- 单选项（如语言）用单列列表，不排成按钮网格；选中态用勾表示，避免和导航的选中底色混淆。
- 外观模式用三张窗口缩略图选择（跟随系统左浅右深），颜色取自当前配色，选中项 2px `accent` 外框。缩略图统一加一圈 14% 细边，深色图在浅底上也有边缘。GPUI 的裁剪是矩形的，缩略图自己画圆角，不依赖父级 `overflow_hidden`。
- 取值少的选项（Tab 宽度、行高）作为设置行右侧的紧凑分段控件，放进卡片，不单独占整行。分段轨道用 `control_bg`，与按钮同一色阶。
