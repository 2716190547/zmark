# 侧栏选择与查找对齐（2026-11-16）

基于 pi t13 的 Q1–Q8 用户答案，由 Codex 接手并自行审查；上一轮功能与目录迁移已完成，本轮不重新实施。

- 控件选中恢复中性色，以每个主题的 surface 混合中性明暗，正文原生选区不变。
- 根目录和子目录不参与选择或范围多选。名称、图标、空白单击立即展开/折叠；名称第二次点击只进入重命名。添加、移除、右键菜单独立处理。
