## 已确认的产品决策

- 文件页顶部固定显示搜索框，保留草稿入口；覆盖已挂载工作区、外部文件与草稿的文件名，不做全文搜索。
- 文件名按不区分大小写的连续子串匹配，不做拼音、模糊匹配或持久化索引。
- 搜索结果过滤目录树，临时展开命中文件的祖先目录；清空搜索后恢复原展开状态。
- 未展开、未载入的子目录也在后台查找，沿用现有扫描预算；触及文件数、条目数或深度上限时，明确提示结果可能不完整。
- 预览支持跨段落拖选、滚动延伸选区及 Cmd+C，复制渲染后的纯文本；覆盖标题、段落、列表、引用、表格与代码块。
- 复制保持阅读顺序、段落换行、列表标记与编号、代码原始换行及缩进；表格使用制表符分列。链接只复制显示文字，不附加地址；不加入 Markdown 格式标记或视觉软换行。
- Source／Split 标题对齐跳过行号后的源码文字起点；Preview 标题对齐居中正文版心。标题使用工具栏以外的可用宽度，空间不足才省略，并保留完整名称提示。
- 默认与 Claude Warm 的选中背景略偏暖，统一应用于侧栏、设置和顶栏；其他调色板保持自身色调，均适配明暗模式。
- 正文使用 macOS 系统字体，源码及代码块保留等宽字体，沿用字号设置；保留图 4 的浅灰代码块背景。

4. 状态栏行列名称走现有多语言体系，简体中文显示“行 / 列”。
5. 灯箱颜色问题沿用 Phase G 修复，在当前版本复验预览与灯箱一致，不根据旧截图重复实现转换管线。

## 已核对的实现事实

- `workspace.rs` 的标题固定 `max_w(320px)`，导致仍有空白时提前截断。
- `editor.rs` 的点击命中按 `font_size * 0.6` 与字符宽度估算；左偏移依赖固定数值，Split 调用额外加入了预览区域偏移。
- `workspace.rs::compute_max_cols` 与 `editor_engine.rs::wrap_line_to_visual` 也依赖估算宽度。仅修点击偏移不能同时保证折行与光标正确。
- 活动行将光标作为 flex 子元素插入文字，光标自身会占据布局宽度，需纳入统一修复。
- GPUI 0.2.2 的 `StyledText::layout` 提供索引与坐标映射；官方 `examples/input.rs` 展示了输入法、选区及实际字形布局的处理方式。可复用能力不等于已有完整输入控件。
- 预览使用虚拟列表和 `StyledText`，没有正文选区管理；不能假设具有浏览器默认选取行为。
- 图片当前显示为图标及 alt/url 占位行，本批仅调整该行间距；真实图片加载不属于这批截图批注。

## 工单顺序与边界

### H0：统一文字布局与点击定位（先行）

以 GPUI 实际文字布局统一点击命中、光标绘制与折行边界，使用内容的实际坐标，删除固定偏移和重复宽度猜测。保留现有编辑缓冲区及撤销行为，不另建编辑器。

先用最小可运行验证确认中英混排、Tab、行内样式与软折行的命中及光标位置；处理 GPUI 字节索引与编辑器字符索引的转换。若实际布局无法直接兼容当前均高虚拟行，先回报具体 API 或布局限制，再调整方案，不用经验宽度系数替代。

涉及 `views/editor.rs`、`editor_engine.rs` 与 `views/workspace.rs` 的布局接入。验证包含 Source／Split、不同分屏比例、侧栏开合、字号变化、窗口缩放，以及同步滚动不回退。

### H1：工作区文件名搜索

实现支持中文输入法的单行输入框、独立焦点及基本编辑行为。搜索输入不得流入源码缓冲区；Cmd+C 等快捷键按焦点路由。

后台遍历复用现有扫描与预算规则，搜索期展开状态不覆盖用户原状态。查询变化、清空、关闭根目录后丢弃过期结果；渲染期不做文件系统 IO。提供清空、无结果、扫描中与结果不完整提示。

涉及 `views/drawer.rs`、`state.rs`、输入控件及 `glidemark_core/src/i18n.rs`；`workspace.rs` 的接入由集成负责人统一修改。

验证中文组合输入、粘贴、同名不同路径、多根目录、未展开目录、深度及数量预算、失效根目录、草稿、外部文件与展开状态恢复。

### H2：预览跨块选区与复制

保留预览虚拟化，选区状态独立于当前可见行；绘制只处理可见文字，复制按文档结构提取对应范围。数据与布局来自当前解析结果，文档切换或重新解析后清除失效选区。

支持双向拖选、滚动延伸、边缘自动滚动和 Cmd+C；列表、表格与代码按已确认规则序列化。代码整块复制按钮继续可用；复制文字不得触发源码编辑或灯箱操作。

涉及 `views/preview.rs` 及最小必要选区状态；`workspace.rs` 的接入由集成负责人统一修改。

验证跨越不可见块的选取、逆向选取、混排字符、嵌套列表、表格局部范围、重复代码块、软折行不新增换行、滚动及解析更新后的状态安全。

### H3：统一选中背景、标题与间距

在现有 ThemeColors 语义方法中调整默认与 Claude Warm 的选中背景，其他调色板保持原有色调；不为单个视图硬编码颜色。保留浅灰代码背景与现有代码换行语义。

标题、编辑正文与预览版心使用相同的对应布局依据，去掉固定 320px 限制。侧栏折叠时保留 ADR 0029 红绿灯安全区；窄窗口不挤掉操作按钮。

收紧图片占位行间距，将状态栏行列文案接入多语言，核对系统字体及等宽字体分工。

涉及 `theme.rs`、`views/workspace.rs`、`views/editor.rs`、`views/preview.rs` 和多语言文案；与 H0/H2 修改同一文件的工作顺序执行。

### H4：独立审查与交付

执行端负责代码和测试，规划端负责文档。同一文件仅一个写入者；可并行推进搜索、配色及独立测试，`workspace.rs` 由集成负责人统一接入，禁止多个代理同时编辑。

独立审查覆盖实际交互、正确性与简化机会；不得只用源代码字符串断言证明光标或选区行为。全量 `cargo test --workspace` 通过后按可独立验证阶段提交，再运行 `./scripts/bundle_macos.sh` 更新本机应用。

交付报告包含 commit、改动文件、测试 passed/failed 数量、逐项验收状态与已知限制。未经明确要求不 push、不建 PR；完成后主动回调 Planner。
