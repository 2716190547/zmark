# ZMark 0.2.15 规划

2026-11-27 制定。来源：GitHub issue #27、#28、#29。

## 范围

### 批次 1：修复

1. **Finder 打开文件显示欢迎页**（#28-3）。`main.rs` 只读 `argv[1]`，没有注册 `cx.on_open_urls`。macOS 通过 Apple Event 传入文件，冷启动和运行中都收不到路径。修复：注册 `on_open_urls`，把 `file://` 路径交给工作区打开。冷启动时如果欢迎页未编辑，就用该文件替换欢迎页。
2. **灯箱缩放方向与捏合**（#28-4）。`lightbox.rs` 在 mac 上固定反转滚轮增量，假设用户开启了「自然滚动」。修复：读取系统滚动方向设置（`NSEvent.isDirectionInvertedFromDevice` 或全局偏好），并处理 GPUI 的 `PinchEvent`，支持触控板捏合缩放。

### 批次 2：体验

3. **欢迎页只显示一次**（#28-2）。在 `Preferences` 中加入「欢迎页已关闭」标记。关闭欢迎页后不再自动生成，设置页提供「打开欢迎页」入口。
4. **侧边栏宽度可调**（#28-1）。把 `DRAWER_WIDTH` 常量改为保存在偏好里的状态，限制在合理范围内。侧边栏边缘加拖拽手柄，双击恢复 250。

### 批次 3：字体与性能基线

5. **字体切换**（#27）。分开设置正文字体和代码字体，界面中的 `UI_FONT`、`MONO_FONT` 常量改为读取偏好。现有 `font_family` 字段尚未生效，需要迁移。代码字体变化时，编辑器的等宽快速折行要重新测量字宽。
6. **预览性能基线**（#29 第 4 点）。用 `ZMARK_FRAME_PROBE` 补充 3 个场景的采样：一万行以上文档的跨屏拖选加滚动、100 个以上单元格表格的划词、长文档连续调整窗口宽度。#29 第 1～3 点的优化留到 0.2.16，按测量数据决定先做哪项。

### 随版发布

- 许可证提交 `4a6a866`、`7bc66fb` 随 0.2.15 一起推送。CI 跑完后确认 Windows 和 Linux 安装包内含 `licenses/`。

## 执行方式

- 在 `dev` 分支按批次提交。日常迭代用 `./scripts/bundle_macos.sh --install` 安装到本机验收。
- 发版前在最终候选上运行 `scripts/full_gate.sh --bundle`，同步更新 README、`docs/releases/v0.2.15.md`。
