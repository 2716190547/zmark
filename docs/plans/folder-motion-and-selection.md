# 文件夹动效与选中态修复

修订：r3（用户已确认，实施中）

## 已确认需求

- 恢复文件夹展开、收起的缓动效果，保留无箭头交互，点击文件夹图标或名称均切换展开状态，双击名称仍重命名。
- 源码、预览与输入框的文字选区采用 macOS 系统选区颜色，保留现有编辑、复制、矩形选择和 IME 行为，不替换编辑器。
- 全部控件的选中背景参照妙言，不再使用当前中性灰。浅色使用 sRGB (0.937, 0.929, 0.894)，深色使用 (0.180, 0.176, 0.169)；文字选区独立于控件颜色。
- 日常本地迭代不运行测试。完成后构建、安装并启动本机版本；推送更新前才运行完整门禁。本轮不推送。

## 证据与边界

- `motion.rs` 保留 600ms ease-out cubic 插值；`WorkspaceView::toggle_folder` 仍建立过渡，render 仍请求后续帧。
- `fading_children` 仅在 0 < value < 1 时设置裁剪高度，端点和嵌套目录的高度计算需要检查；早期调查尚未确认完整故障根因；最终名称入口根因见文末。
- `reduce_motion` 启用时跳过动效是现有行为，必须保留并与真实动画回归区分。
- GPUI 正文由自绘选择逻辑实现；系统原生指采用系统语义颜色，而非替换成 NSTextView。
- 妙言参考： https://github.com/tw93/MiaoYan/blob/main/Resources/Images.xcassets/selectionBackground.colorset/Contents.json 。公开仓库参考，不宣称与闭源版本完全相同。

## 执行方案

1. 在实际界面观察根目录、子目录的展开与收起，检查本机减少动态效果偏好。核对触发回调、插值、后续帧通知、裁剪布局，先确认根因，再做最小修复。保持中途反向切换连续、完成后静止、无持续动画帧。
2. 控件共用 `control_selection_bg`，改用妙言的明暗两色；不改变文字选区。核对侧栏、顶栏、设置、补全列表和预览操作按钮调用。
3. macOS 在主线程读取 AppKit 公开系统语义颜色并按应用当前明暗模式解析。文字选区同时使用 selectedTextBackgroundColor / selectedTextColor；窗口失活时使用 unemphasizedSelectedTextBackgroundColor / unemphasizedSelectedTextColor。选中范围内语法色被系统前景色覆盖，取消选择后恢复；控件前景仍用 theme.text_primary，不能把现有 selection_text 全局替换。源码和预览接入完整的系统前景与背景。gpui-component 输入框仅暴露选区背景，使用系统背景并保留主题文字色，不替换组件；用户已确认这一替代实现。保留各区域原有失焦后是否保留选区的行为。首次启动、应用明暗切换、窗口重新激活时刷新并缓存颜色；系统偏好变化不增加全局监听，最迟重新激活后生效，不承诺前台即时热刷新。非 macOS 保持既有回退。
4. 同步术语表中已过时的 Selection Token 定义，区别控件选中态与文字选区。这是可逆 UI 调整，不新增 ADR。
5. 构建并本机安装；如实报告未跑测试及手工验证范围。

## 验收

- 小目录、大目录及已有展开子层的嵌套目录，从收起展开、展开收起均可观察到连续高度变化和缓动；快速反向无跳变，关闭目录不接收隐藏行点击；减少动态效果时直接切换。
- 源码、预览、搜索、重命名输入框选区跟随系统颜色；选区边界、文字内容、复制和 IME 不发生行为变化。
- 明暗模式下各类控件用同一套妙言背景色，选中文字与普通文字可读；控件颜色不污染正文选区。
- 本机 release 构建和签名安装成功；未经测试的范围明确记录，不声称自动回归通过。

## 实施发现与最终范围

- 用户明确复现入口是“点击文件夹名称，目录没有展开或收起”。名称回调原先只设置 selected_directory，没有调用 toggle_folder，因此没有启动过渡；现让名称单击进入与图标一致的 toggle_folder，双击仍重命名。
- 另修复过渡值为 0 时未限制高度、嵌套过渡高度未乘进度的问题。父容器外部 gap 保持固定，与真实布局一致；完成展开后恢复自然高度以显示空目录提示等内容。
- 侧栏文档与文件夹图标统一 14px 并禁止压缩，修复长文件名使图标大小不同的问题。
- 不新增动画帧调度机制：独立源码核查确认原 request_animation_frame 已通知 WorkspaceView；旋转 SVG 不负责调度帧，删除箭头不是帧停止的直接原因。

## 2026-11-28 手感调整

- 展开收起从 600ms ease-out cubic 改为 220ms ease-out quint，与侧栏滑动、块编辑过渡的时长一致（`FOLDER_MOTION_MS`）。
- 子项透明度不再和高度同步线性变化：展开时先于高度淡入（`value × 1.6` 封顶），收起时前 3/8 行程保持不透明，到末段才淡出，避免内容还在可见区域时就发灰。
- 只改手感，不改过渡的触发、反向连续和隐藏行拦截逻辑。
- 帧探针无法量化这次改动：不切换文件夹的对照也有 12–17 帧超过 16.7ms（探针启动与解析的背景噪声），所以只能靠目视验收。探针场景未保留。
