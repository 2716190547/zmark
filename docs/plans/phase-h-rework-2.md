## 阶段 A 补修：44e61d8 复审打回后的三个 P1

已经通过且须保留：真实折行确已接入渲染/上下导航/源码→预览滚动，Tab 与行内代码内边距已生效；双写路径已消除；B6 的 22 项图标注册与加载全部通过。本轮不再重做这些内容，也不推进阶段 B。

1. **正常字符输入被阻止**：`drawer.rs` 对未显式处理的普通按键调用 `stop_propagation`，导致 GPUI 提前返回，系统文本输入回调不执行。必须让普通字符与组合文本到达唯一的输入处理链路，仅对已经处理的键阻止传播。审查在隔离副本移除该拦截后复现 `ab + x → abx`、`left left z → azbx`、`shift-left q → aqbx`、`cmd-a r → r`，当前版本则完全不插入。
2. **搜索焦点标志残留吞编辑器输入**：搜索后点击编辑器，`search_focused` 仍为真，Workspace 的搜索分支提前返回。须以实际焦点路由，不依赖 Escape 才恢复；覆盖搜索→编辑器点击→输入、再次回到搜索的完整事件序列。不得重新引入手工拼接搜索字符串的路径。
3. **每次按键在 Render 同步重排全文**：修改 revision 即失效全文缓存，独立实测 500 行约 27.3ms、2000 行约 166.5ms，较旧估算慢约 17–20 倍。保留真实布局，通过复用未变行的度量/折行结果等最小方案，将普通单行编辑的 shaping 限制到受影响内容；不能退回估算宽度。围栏语义改变需要正确传播失效，字号/窗口/分屏变化仍需正确重排。除了实际计时前后对比，增加稳定的工作量或缓存复用检查，防止用宽松的时间阈值掩盖全文重排。

同轮修复 B4 的反向同步滚动：`preview_to_source_line` 返回物理行号，不能直接当视觉行索引传给 `scroll_to_item_strict`；两方向使用同一真实折行映射。覆盖前方存在多段软折行的定位场景。

**失败检查必须从真实事件入口触发**：搜索至少用 `simulate_keystrokes` / `Window::dispatch_keystroke` 及实际注册的输入处理器驱动可打印字符、移动后插入、替换、全选、搜索与编辑器焦点切换。直接调用 `handle_replace_text` 等方法不能作为这些 P1 已修复的证据。

Workspace 级真实折行验证包含有区分力的例子（5 Tab 与行内代码为 1 行，而原估算为 2 行），不能只断言结果非空。保留独立测试代理的红→绿和临时回退检验，提交前全量测试，按“阶段 A 补修”回调协调端独立复审。未通过前不打包、不推进阶段 B。

## 阶段 B：修 B1、B2、B3 及剩余问题

预览回归检查要从生产鼠标事件到高亮范围及剪贴板结果，覆盖段内、跨块、嵌套列表、引用、表格、滚动后坐标、反向选择、边缘持续滚动及拖出释放。

同时处理关联状态：

- Cmd+C 按焦点及视图模式路由；Source 聚焦时不复制旧预览选区，模式切换清除或隔离旧选区。
- 选取中状态不能捕获过期渲染快照；鼠标释放、失焦和文档切换统一终止。
- 后台搜索避免每按一键在 UI 线程深拷贝大树；结果应用不得覆盖扫描期间用户的新树状态；失败后必须结束扫描中状态，允许重试。
- 保留已达成的固定顶部搜索、后台扫描 generation 防过期、稳定根身份及 H3 视觉行为。
- 补齐真实焦点转换回归，清理无焦点兜底吞键和不可达的重复 Escape 处理；搜索文本仍只能由系统输入处理器修改。
- 评估并改善连续拖动分屏或抽屉动画的宽度变化成本：审查实测 2000 行约 93ms/步、10 步约 837ms。避免在每个中间宽度重复全文字形度量，最终宽度必须准确排版，不能通过忽略尺寸失效、错误量化宽度或恢复估算破坏命中及滚动。记录前后数据与正确性回归；不能解决时提供证据供独立终验评估，不隐瞒。

删除未接入的旧估算 API、旧块级选区兼容层、无生产调用的 perform_search/spawn_background_search/file_matches_search、ActiveLineSegment 及无意义的 allow(dead_code)。有明确生产用途的真实布局方法应接通而非机械删除。

新增 search.svg 的风格纳入现有图标约束检查。按 `ponytail-review` 检查重复与无效层，不为了追求行数重构已通过部分。

生产选取测试必须在非零视图原点、实际滚动和嵌套内容下派发鼠标事件，核对真实高亮范围与剪贴板；同时用可控时间验证指针不移动时仍持续自动滚动、松开/失焦后停止。产品内自动滚动的计时或帧回调不属于协作轮询；禁止的是用定时器反复探测代理状态。
