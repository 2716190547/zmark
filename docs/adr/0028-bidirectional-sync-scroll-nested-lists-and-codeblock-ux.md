# ADR 0028: 双向同步滚动、递归嵌套列表与代码块横向滚动交互架构

## 状态
已接受 (Accepted)

## 上下文 (Context)
在 Phase 1 正确性与排版交互访谈中，梳理并确认了以下三项核心体验短板与约束：
1. **分屏（Split）缺乏真正可用的同步滚动联动**：
   - 此前核心层虽存在 `SyncScrollMap` 与源码锚点映射计算，但应用层未完整接入双向驱动；
   - 在双向滚动中若缺乏回声抑制机制，容易引发死循环或视口抖动；
   - 处于连续编辑输入状态且 AST 处于 stale 防抖等待时，若频繁执行估算映射会导致视口上下跳动。
2. **列表解析扁平化且丢失行内富文本**：
   - 早期 `collect_list_items` 将嵌套列表直接拍平，且在遇到粗体、斜体、链接、删除线等内联标记时全部丢弃，严重破坏 Markdown 文档结构与阅读排版；
   - 导出为 HTML 时亦未按照 HTML5 规范将子列表封装在父级 `<li>` 容器中。
3. **代码块长行折行破坏版式与复制无反馈**：
   - 代码块此前直接软换行，导致缩进对齐紊乱且行号错位；
   - 代码块头部的复制按钮此前仅有 Tooltip 悬浮提示，未绑定实际系统剪贴板写入与瞬时成功视觉反馈。

## 决策 (Decision)

### 1. 双向最后操作优先同步滚动 (Bidirectional Last-Interacted Sync Scroll)
- **触发与范围约束**：
  - 同步滚动仅在分屏模式（`ViewMode::Split`）下生效；
  - 仅响应用户主动触发的鼠标滚轮与触控板滑动（`ScrollWheelEvent`），不侵入键盘常规文本编辑与光标位移。
- **100ms 回声抑制 (Echo Suppression)**：
  - 记录最后一次滚动的来源（`ScrollOrigin::Editor` 或 `ScrollOrigin::Preview`）及高精度时间戳；
  - 当另一侧在 100ms 内收到由于联动同步触发的位移回显时，自动跳过反向驱动，彻底消除循环联动震荡。
- **编辑输入防抖对齐策略 (Pause on Edit, Align on Debounce)**：
  - 编辑输入导致文档内容处于 `parse_stale` 阶段时，暂停双向同步，保持当前阅读视口平稳；
  - 当文档大小分级防抖定时器触发并完成全量解析后，系统自动读取当前编辑器光标所在行，将预览区平滑对齐至该行对应的块级元素。

### 2. 递归嵌套列表与全格式行内渲染 (Recursive Nested Lists & Inline Styling)
- **AST 扩展与深度护栏**：
  - `ListItem` 增加 `sub_list: Option<Box<BlockElement>>`；
  - `collect_list_items` 支持递归向下探测多层级列表，并设定硬上限为 8 层，防范恶意或畸形深层嵌套导致的堆栈溢出；
  - 统一提取 `handle_inline_event` 处理器，完整保留嵌套列表项中的粗体、斜体、删除线、行内代码、超链接与任务清单复选框。
- **排版渲染与 HTML 导出规范**：
  - 预览层 `render_list_element` 支持子列表内缩 `pl_5`，无序列表项按层级循环递进呈现 `–`、`◦`、`▪` 三级符号；
  - HTML 导出模块遵循标准 HTML5 规则，将嵌套的 `<ol>` / `<ul>` 规范输出在父级 `<li>` 标签内部。

### 3. 固定行号列、横向平滑滚动与 1.2s 复制反馈 (Code Block UX)
- **固定行号与横向滚动隔离**：
  - 行号列设置为固定宽度、`flex_shrink_0` 并带有右边框隔断；
  - 代码主体容器分配独立状态标识并启用 `.overflow_x_scroll().whitespace_nowrap()`，保证代码在长行时不换行、可沿 X 轴独立横向滚动，不破坏主画布纵向阅读节奏。
- **剪贴板写入与 1.2s 对勾反馈**：
  - 点击代码块头部复制按钮时，通过 GPUI `app.write_to_clipboard` 写入原始纯文本代码；
  - 记录当前代码内容哈希与触发时刻，按钮图标即时由复制图标切换为高亮对勾（`icons/check.svg`），Tooltip 切换为“已复制”；
  - 异步定时器经过 1.2 秒（1200ms）后自动静默恢复为默认复制状态。

## 结果 (Consequences)
- **正面收益**：
  - 彻底打通分屏模式下的双向精准滚动联动与输入防抖光标追随，操作平滑无抖动；
  - 列表结构支持任意常见 Markdown 嵌套层级，行内样式完好无损，HTML 导出符合规范；
  - 代码阅读与复制体验完全符合现代主流开发者习惯，长行排版工整，交互反馈明确；
  - 零新引入任何外部第三方大体积依赖，100% 依托 GPUI 原生机制与纯 Rust 标准库构建。
