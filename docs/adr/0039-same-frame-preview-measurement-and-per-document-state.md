# ADR 0039：预览同帧测量与按文档保存的编辑、预览状态

状态：Accepted，2026-11-28。代码 `f8f5233`（同帧测量、按文档状态）、`5835b99`（帧探针场景与测量），图片与 Mermaid 尺寸记忆随本 ADR 提交。Phase H/I 专项按项目约定在发版门禁运行，本 ADR 写成时尚未在新代码上运行。

## 背景

预览由 `PreviewScrollState` 的高度表驱动（ADR 0026）。旧做法先按高度表给块定位，未测量的块使用估算高度；块绘制时由 canvas 记录真实高度，下一帧才修正。用估算高度排版的那一帧会显示出来，表现为空行和内容跳动。重新解析（如勾选任务复选框）、调整行高、切换文档都会让高度表失效，因此都会触发。

切换文档时还会清空撤销历史、高度表、滚动位置和语法着色缓存，回到原文档后既不能撤销，预览也要从估算高度重新开始。

## 决策

1. **可见块同帧测量**。新增 `views/preview/measured_blocks.rs`。prepaint 阶段对每个可见块调用 `layout_as_root` 取得真实高度，从首块在高度表中的位置起按真实高度向下排列，再 `prepaint_at`，同一帧完成绘制。真实高度上报给高度表，高度表以视口顶部块为锚点更新，下一帧位置与本帧一致。块不再使用 `absolute`、`top` 和按估算值的 `min_h`。
   - 参照 GPUI `list()` 的 prepaint 测量方式，但保留自己的高度表：屏幕外的块仍用估算值，只影响滚动条长度。`ListState` 只知道已测量块的高度，滚动条会跳，这是当初不用它的原因（见 `virtual_list.rs` 开头），仍然成立。
   - 如果真实高度比估算值小，本帧会继续构建后续块直到填满视口，最多多构建 64 块。
2. **高度在重新解析后延续**。新 AST 与旧 AST 逐块比较公共前缀和公共后缀，未变的块沿用旧的真实高度。行高或字体变化后旧高度仍先沿用，再由同帧测量更新。
3. **按文档保存状态**。
   - 编辑会话：撤销/重做、光标和选区存放在 `OpenDoc.session`。后台文档的历史合计不超过 32 MiB，超出时先清最大的历史。
   - 预览：切走时保存高度表中的真实高度和顶部块位置，切回时按缓冲区哈希校验，内容没变才复用。
   - 语法着色缓存按代码内容和语言索引，切换文档时不再清空。
4. **异步内容预留尺寸**。图片解码过一次后，按文档和 URL 记住像素尺寸；被移出视口释放后重新解码时，占位块使用相同的宽高比和最大宽度。Mermaid 记住 SVG 尺寸，重新解析时按该尺寸显示空卡片。首次加载仍无法提前得知尺寸，加载完成时下方内容会移动一次。

## 与既有决策的关系

- **ADR 0026**：保留高度表、分层解析和延迟同步滚动；只替换可见块的定位方式。
- **ADR 0037**：预览文字区域仍在每帧按实际绘制位置登记，命中测试、选区和复制语义不变。区域登记从 render 后的布局改为 `MeasuredBlocks` 的 prepaint，位置来源仍是实际布局。

## 测量

release 构建，120Hz 屏，窗口在前台，结果见 `docs/plans/v0.2.16-plan.md`。与 0.2.15 相比，拖动滚动和表格划词持平，连续改窗口宽度的 p50 从 13.9–14.9ms 降到约 9.3ms。新增的 `doc-switch`、`task-toggle`、`line-height` 场景结束时视口都停在起始块。帧时间不能证明没有空行；这一点由「先测量再定位」的结构保证，仍需人工目视验收。

## 边界

- 每帧对可见块多做一次根布局。可见块通常十几个，探针数据未见回归。
- 首次加载的图片和 Mermaid 仍会在加载完成时改变高度。
- 帧探针需要屏幕解锁、窗口在前台才会出帧。
