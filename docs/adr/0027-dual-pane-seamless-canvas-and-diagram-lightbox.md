# ADR 0027: 双板块无界纸张画布、动效红绿灯迁移与矢量图表灯箱架构

## 状态
已接受 (Accepted) - 已落地（提交 f8ca3e5、3c37807、b3a8e01）；红绿灯受 GPUI 0.2 限制采用静态位置 + 76px 安全区，详见 ADR 0029

## 上下文 (Context)
在对比最新版“妙言 (MiaoYan)”设计语言与 GlideMark 当前界面的实机审视中，定位出以下核心视觉与交互优化空间：
1. **选中态对比度过高破坏平静感 (High-Contrast Selection)**：
   - 当前 GlideMark 列表与 Tab 选中状态采用高饱和度强调色实心色块（如陶土红纯色填充搭配反白文字），在视觉上过于抢眼，违背了极简书写与阅读所追求的克制与呼吸感。
   - 新版妙言采用低饱和度、素雅温润的暖米灰微胶囊衬底（`#EBE7DE`），文字维持深色灰黑（`#1E1E1E`），极大降低了视觉疲劳。
2. **通栏顶栏与多重横线造成视觉切割 (Horizontal Fragmentation)**：
   - 当前界面顶部常驻一条横跨全屏的独立顶栏，下方紧跟一条贯通横线；右侧内容区内部又嵌套了标签页横条及其下方的分割线。
   - 多道横向分割线将视窗横向切裂为多个碎片层级，破坏了纸张一体感。
3. **文件夹图标语义重复与侧栏功能单一 (Duplicate Folder Icon)**：
   - 顶部工具栏已存在打开文件/文件夹功能，侧边栏头部又独立占用了一个「打开文件夹...」的 Tab 图标，功能冗余；
   - 侧栏此前仅支持同级扁平文件列表，缺乏真正的多层级工作区目录树浏览能力。
4. **嵌入式流程图小字阅读困难 (Diagram Legibility)**：
   - 复杂的 Mermaid 架构图或流程图在排版正文中受限于阅读列宽，图元与文字等比缩小后难以辨认细节，缺乏点击放大查看全貌的交互手段。

## 决策 (Decision)

### 1. 双板块纯竖向一体无界画布 (Dual-Pane Seamless Canvas)
- **彻底去除横向通栏顶栏与横向分割线**：
  - 界面仅划分为左右两大全高贯通板块：**左侧导航板块 (Navigation Pane)** 与 **右侧内容画布 (Content Canvas)**；
  - 两大板块之间仅保留一条 1px 极细竖向发丝分割线（`#E6E4DE` / `#ECECEC`），消除所有水平底边线，形成如同天然纸张般的垂直连续性。
- **右侧头部内嵌微标签栏与工具集 (Integrated Header)**：
  - 右侧内容区顶部自然留出 38px 头部控制区，背景与正文完全平齐融合（0 像素横线）；
  - 左侧内嵌多文档微标签页（支持新建 `+`、关闭 `x`、脏状态指示），右侧依次排列模式分段切换器（源码 `<>` / 分屏 `|` / 预览 `book`）与核心动作按钮（保存、导出 HTML、偏好设置）。

### 2. 自适应跨平台窗体控制与侧栏折叠 (Dynamic Window Inset)
- **macOS 红绿灯自适应迁移**：
  - **侧栏展开态**：红绿灯自然内嵌于左侧导航栏左上方（`pl(px(16.)) pt(px(14.))`），其右侧放置「收起侧栏」图标；
  - **侧栏折叠态**：左侧栏平滑收起至 0px；红绿灯控件无缝映射至右侧画布左上角，右侧画布头部自动注入 `pl(px(76.))` 安全避让内边距，并紧随红绿灯后方渲染「展开侧栏」图标；
  - **窗口拖拽区域 (Window Dragging)**：左栏头部空隙与右栏标签栏与工具区之间的空白区域均声明为系统原生窗口拖拽感应区。
- **Windows / Linux 标题栏控制区适配**：
  - 右侧头部右上角自动探测操作系统平台，非 macOS 环境下在工具按钮右侧保留 `pr(px(138.))` 预留区，用于承接系统原生的最小化、最大化和关闭按钮，确保全平台体验一致。

### 3. 工作区目录递归树 (Workspace Tree)
- **去除冗余独立 Tab**：侧栏头部收敛为两个核心视图切换器：**文件树 (Files)** 与 **大纲 (Outline)**。
- **递归折叠树交互**：
  - 支持多级子目录展开/折叠（带平滑旋转 Chevron 指示符）；
  - 顶部显式标注当前工作区根目录名，并提供轻量级「切换文件夹」快速入口；
  - 用户从访达（Finder）拖入或双击打开单份 `.md` 文件时，系统自动解析并将其父级目录作为默认工作区展开，兼顾单文件即时阅读与工程化浏览。

### 4. 暖石微胶囊低反差选中态 (Subtle Warm Pill)
- 全面淘汰刺眼的高饱和度强调色实心色块填充；
- **浅色模式**：选中项采用暖米灰微胶囊背景（`#EBE7DE`），文字维持原生深灰（`#1E1E1E`），保留 6px 圆角；
- **深色模式**：选中项采用低反差暗陶土微胶囊（`#2A2826`），文字采用自然暖白（`#E5E2DC`）；
- 整体视觉克制沉静，与正文纸张质感高度协调。

### 5. 纯矢量全屏图表灯箱 (Vector Lightbox)
- **触发交互**：鼠标悬停正文 Mermaid 图表时显式浮现放大提示微光晕与放大图标；点击图表即刻调起灯箱。
- **模态表现**：
  - 150ms 优雅淡入半透明深色磨砂遮罩（`rgba(0, 0, 0, 0.45)`）；
  - 图表以 100% 原始矢量精度居中投影渲染，杜绝任何位图锯齿模糊；
  - **交互控制**：支持触控板双指捏合与鼠标滚轮平滑无级缩放（0.2x ~ 5.0x），支持按住鼠标左键全景拖拽平移（Pan）；
  - **悬浮控制器 (Floating HUD)**：底部居中渲染半透明药丸控制条：`[ - ] [ 100% ] [ + ] [ 适应窗口 ] [ 关闭 (Esc) ]`；
  - 支持点击遮罩空白区域或按键盘 `Esc` 键平滑退出。

## 结果 (Consequences)
- **正面收益**：
  - 消除多重顶栏与水平分割线，整体界面纯粹、通透，完全达到现代高级社论印刷品的美学高度；
  - 解决了侧栏功能重复问题，赋予 GlideMark 完整的项目级多层级 Markdown 目录管理能力；
  - 彻底攻克复杂流程图在窄版心下字小难辨的顽疾，提供原生桌面级的高清矢量缩放查看体验；
  - 严谨规范了 macOS 红绿灯折叠位移与 Windows 控制按钮的跨平台布局边界。
- **实施结果**：
  - 双板块画布、内嵌 38px 头部、暖石微胶囊、递归工作区树与矢量灯箱均已落地。
  - macOS 红绿灯无法运行时迁移，采用静态位置 + 侧栏折叠 76px 安全区的替代方案，边界见 ADR 0029。
