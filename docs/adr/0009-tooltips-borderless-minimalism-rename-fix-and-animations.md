# ADR 0009: 全局图标 Tooltip 提示、去边线极简层级、标题双击改名修复与原生微动效

## 状态
已接受 (Accepted)

## 上下文 (Context)
在用户实际体验与视觉审视中，提出了以下核心需求与体验优化：
1. **全局缺乏 Hover 提示**：顶栏功能图标、模式切换、抽屉 Tab 缺少快捷键与操作说明，新用户难以直观了解功能与快捷键；
2. **视觉层级与边线冗余**：界面内嵌套过多的边框（如抽屉 Tab 边框、顶栏模式切换框、抽屉分割线等），违背了“妙言”风格的极简呼吸感与留白原则；
3. **文件名双击无法输入改名**：双击顶栏文件名进入编辑态后，无法打字输入或按退格修改，键盘事件未能正确路由至改名缓冲区；
4. **缺乏细腻微动效**：侧边栏抽屉展开收起、设置模态唤出与按钮交互缺少平滑过渡，视觉体感偏生硬。

## 架构决策 (Decisions)

1. **GPUI 原生 Tooltip 微胶囊体系**:
   - 封装统一的 `SimpleTooltip` 视图组件，呈现深色半透明胶囊、清晰字体与快捷键标记（如 `打开文件 (⌘O)`、`双栏分屏 (⌘2)`）；
   - 利用 GPUI 的 `StatefulInteractiveElement::tooltip` 机制，在所有顶栏操作按钮、模式切换胶囊与侧边栏 Tab 上实现悬停 300ms 优雅浮现。
2. **去边线与扁平化层级重构 (Borderless Minimalism)**:
   - 全面剔除抽屉顶部双 Tab 容器的硬性 1px 外框与内框，改用轻盈的纯色悬浮背景与强调色激活状态；
   - 弱化顶栏与工作区分割线为发丝级微透明线条，去除模式切换控件的多层边线；
   - 减少多余的内边距与视窗嵌套，增强留白与呼吸感。
3. **标题双击原地内联改名引擎修复**:
   - 根因分析：此前双击时未调用 `window.focus(&this.focus_handle)`，导致键盘事件未能派发给 `WorkspaceView` 的按键监听器；且改名缓冲区未能在激活时全选或响应点击聚焦。
   - 工程解决：双击时显式获取焦点，渲染带强调色聚焦微外框与活动光标的输入控件，支持打字追加、退格删除、`Enter` 提交磁盘重命名（自动同步文档路径与刷新同级文件列表）以及 `Esc` 放弃还原。
4. **原生 GPU 微动效驱动 (AnimationExt)**:
   - 接入 GPUI 原生 `AnimationExt::with_animation` 与 `easing::ease_out_quint` / `ease_in_out`；
   - 侧边栏抽屉展开/收起实现 180ms 平滑宽度伸缩与透明度淡入；
   - 偏好设置模态窗口实现 150ms 缩放淡入；
   - 按钮与 Tab 悬停实现平滑颜色过渡。

## 影响 (Consequences)
- 界面视觉极大简化，符合高级极简编辑器水准；
- 解决了无法重命名文件的核心可用性缺陷；
- 赋予应用丝滑流畅的交互手感与完善的功能指引。
