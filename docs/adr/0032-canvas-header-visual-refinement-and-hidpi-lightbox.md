# ADR 0032: 视觉层级精进、无感知全屏适配与 HiDPI 流程图重采样灯箱

## 状态
已接受 (Accepted) - 达成审查与产品共识，进入实施

## 上下文 (Context)
在 Phase B 多文件夹联合工作区落地后，日常深度使用中发现以下 6 处直接影响使用体验的细节：
1. **全屏侧栏空隙**：macOS 全屏模式下红绿灯自动隐藏，但侧栏顶部依然硬编码 `px(76.)` 左边距，留下大片突兀的无效空白。
2. **侧栏草稿层级反直觉**：侧栏最上方常驻“草稿”大分组标签，即便未打开草稿也常驻灰色占位项，割裂了多文件夹工作区的直觉浏览体验。
3. **文档大标题视觉比重偏轻**：38px 头部内当前文档大标题字号仅 14px，视觉重心未能与右侧按钮水平中心稳重对齐。
4. **视图切换按钮过度强调**：源码/分屏/预览三档按钮外层包裹了厚重的分段边框容器，与右侧平铺的保存/导出/设置按钮在视觉节奏上产生割裂。
5. **流程图放大入口破坏严肃规范**：卡片右上角使用 `🔍` Emoji 与长文本（“点击放大查看流程图”），违背零 Emoji 严肃排版规范。
6. **灯箱放大位图模糊**：Mermaid 流程图在灯箱放大至 200%~400% 时有严重锯齿与失真，因原架构受限于 1000px 固定纹理栅格化尺寸。

## 决策 (Decisions)

### 1. 全屏动态自适应左边距
- 在 `render_drawer` 与 `render_canvas_header` 中引入动态全屏判定：
  - 非全屏模式：维持 `px(76.)`，确保不遮挡 macOS 原生红绿灯按钮；
  - 全屏模式（`window.is_fullscreen()`）：自动平滑缩减为 `px(12.)`，彻底消灭全屏状态下的顶部大空隙。

### 2. 侧栏草稿组织去中心化
- 彻底移除常驻的“草稿”一级大分组标题及未打开时的空占位项；
- 没打开草稿时，侧栏零占用、零干扰，直觉呈现工作区文件夹树；
- 当用户按 `Cmd+N` 或打开无路径临时文档时，草稿自然展示在文档列表顶部或外部文件分组首项，支持悬停微型 `[×]` 关闭与脏数据保护。

### 3. 右侧大标题字号提升与严格垂直居中
- 当前文档标题字号提升至 **15px**，保持 **Semibold** 字重；
- 在 38px 头部高度内严格通过 Flexbox 居中对齐，与右侧工具栏操作按钮处于绝对同一水平视觉中线。

### 4. 视图切换按钮彻底去边框平铺与暖石统一
- 彻底移除视图切换按钮外层的 `border_1()` 分段边框容器与加深底色；
- 三个视图模式图标与右侧的保存、导出、设置按钮平铺统一对齐；
- 选中项样式与左侧栏文档选中项保持一致，采用统一的高级暖石微胶囊底色（`theme.warm_pill_bg()` / `theme.warm_pill_text()`）。

### 5. 流程图放大入口纯 Icon 化
- 彻底移除 `🔍` Emoji 与“点击放大查看流程图”文字；
- 改为流程图卡片右上角悬停显现的纯矢量微图标按钮（`icons/maximize.svg` 或内置展开 svg），悬停呼出本地化 Tooltip，默认半透明，悬停高亮。

### 6. HiDPI 超清流程图灯箱重采样
- 针对灯箱全屏预览与高倍缩放场景，提供专用 HiDPI 纹理预算（`max_dimension: 3600.0`）；
- 经由矢量 SVG 动态重采样，即便在灯箱内放大至 400%，文字排版与边框线条依然保持矢量级丝滑锐利、零像素模糊。

## 分期与 Ticket 落地规划
- **Ticket C1 (Header & Drawer Polish)**：全屏左边距动态感知、侧栏常驻草稿分组移除、大标题字号与中线对齐、视图模式平铺去边框与暖石统一。
- **Ticket C2 (HiDPI Lightbox & Icon Button)**：流程图卡片纯 Icon 放大按钮、HiDPI 3600px 纹理支持与灯箱超清放大、对应测试用例。
- **Ticket C3 (Integration & Verification)**：全量回归测试、构建更新 `/Applications/GlideMark.app`、文档索引更新与 Reviewer 终验签字。

## 结果 (Consequences)
- 全屏沉浸式体验大幅提升，消除顶部空隙；
- 侧栏结构更紧凑自然，不再被静态空草稿干扰；
- 顶部导航栏视觉节奏完全统一，大标题更有分量；
- 流程图在灯箱高倍缩放场景下彻底达到印刷级矢量清晰度，彻底杜绝模糊。
