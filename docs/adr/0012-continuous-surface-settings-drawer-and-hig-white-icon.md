# ADR 0012: 通栏沉浸纸张布局、右侧平滑设置抽屉与 Apple HIG 白底 Squircle 图标

## 状态
已接受 (Accepted)

## 上下文 (Context)
1. **设置窗口同步调用触发 GPUI 借用 Panic 闪退**:
   - 在工作区点击设置按钮时，内部同步调用 `cx.open_window` 立即初始化 `SettingsWindowView`，其渲染函数同步调用 `self.workspace.read(cx)`。
   - 此时 `WorkspaceView` 正被外层事件监听器以可变引用（`&mut WorkspaceView`）借用，触发 Rust 致命重入借用崩溃（`BorrowError: already mutably borrowed`），AppKit 抛出 `SIGABRT`。
2. **浮动大圆角卡片布局破坏沉浸写作感**:
   - 之前的浮动卡片架构（外围 8px 灰色槽、`rounded_xl` 12px 圆角及边线）不仅浪费宝贵的横向可视宽度，而且使 Markdown 编辑器呈现出 Web SaaS 仪表盘/后台管理系统的视觉疲劳感，违背了 Markdown 桌面排版的“沉浸纸张”呼吸原则。
3. **App 图标在 macOS 浅色 Dock 上呈现为发灰方块**:
   - 此前为避免边缘溢出而将图标设为 100% 全透明，但在 macOS 浅色模式 Dock 栏下，系统毛玻璃底板将整块透明区域衬托为灰暗暗沉的灰色方块，用户明确要求还原为饱满的纯白底色（`#FFFFFF`）。

## 决策 (Decision)
1. **右侧平滑滑出设置抽屉 (In-Window Settings Drawer / Sheet)**:
   - 彻底摒弃易产生借用冲突的独立原生子窗口，采用现代专业桌面工具（Linear / Craft）主流的**右侧抽屉式滑动面板**。
   - 宽度固定为 380px，支持 180ms 平滑滑入滑出微动效，左侧配有 1px 精致发丝分割线。
   - 顶部包含关闭按钮（`X`）与“偏好设置”标题，次级导航包含四大胶囊分段选项卡（外观主题、编辑器与保存、语言、关于）。
   - **零崩溃风险**：与主工作区共用同一窗口与渲染帧生命周期，杜绝跨窗口实体借用冲突；且修改调色板与主题时主窗口左侧文档即时无缝联动。
2. **通栏沉浸纸张与微色调分层布局 (Continuous Surface & Tonal Hierarchy)**:
   - 移除外层 8px 冗余边距与各面板外浮动卡片圆角，编辑器与阅读预览区撑满可用高度，保持纯粹通透。
   - **色调分层**：
     - 左侧大纲/文件抽屉与右侧设置抽屉采用温和微浅雾灰底色（`theme.bg = #F4F4F6`，暗色为 `#131315`），构成清晰低噪的控制面层级。
     - 核心编辑与阅读区采用纯粹沉浸的纸张底色（`theme.surface = #FFFFFF`，暗色为 `#1E1E22`）。
   - **居中阅读排版**：预览区正文包裹在 `max_w(px(max_column_width)).mx_auto()` 中，在超宽大屏下自动保持最佳阅读列宽（780px），杜绝无限拉伸。
   - **发丝级中间分割线**：分屏中间采用 5px 交互感知触发区与 1px 细线，鼠标悬停时激活品牌强调色微高亮。
3. **Apple HIG 标准白底 Squircle 图标规范**:
   - 在 1024x1024 容器中心绘制标准 824x824 Squircle（连续曲率圆角矩形，半径 ~185px），背景采用纯白 `#FFFFFF`，并施加 1px 超微弱灰度边界描边（`rgba(0,0,0,0.06)`）确保在全白桌面上依然具有清晰边缘。
   - 底层叠加标准 macOS 向下软阴影（垂直偏移 18px，高斯模糊 18px，alpha 0.18），立体而不厚重。
   - 中心居中摆放 GlideMark 暖色红褐至金黄琥珀渐变 Z 标志，尺寸 480x480。

## 结果 (Consequences)
- 彻底根除点击设置引发的 Rust 借用重入崩溃问题，`⌘,`、工具栏按钮与 `Escape` 键均可丝滑切换设置抽屉。
- 界面彻底摆脱 Web SaaS 仪表盘卡片感，呈现 MiaoYan / Bear 2.0 级别的通栏呼吸质感与居中阅读排版。
- Dock 栏图标在浅色与深色 macOS 主题下均呈现清晰纯白立体底座与醒目标志，彻底告别灰色发暗。
- 工作区 30 个自动化单元与集成测试全部通过，macOS release 打包安装测试正常。
