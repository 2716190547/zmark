# ADR 0035: 无缝贯穿设置视窗、系统化调色推导、图标线宽归一、点部语义上色与 Mermaid 语法脱糖

## 状态
提议中 (Proposed) - 经过 Frontier Decisions 用户交互确认，提交审查端初审

## 上下文 (Context)
在 Phase E（软折行与 CJK 点击对齐）交付并全绿验收后，用户提供了 3 张核心视觉与功能标注图（图 1 设置视窗问题标注、图 2 标杆妙言排版与色彩样张、图 3 主视窗问题标注）：
1. **设置窗口割裂上下堆叠 (图 1)**：当前设置视窗在顶层硬编码了一个 44px 的顶部横条，包含了红绿灯占位与“设置”文字，将窗口横切成上下两截，下方才是左右两栏。与主 App 的抽屉贯穿风格以及 macOS 原生设置界面不一致，割裂感严重。
2. **外观模式等控件选中色生硬倒错 (图 1)**：当前分段控件（跟随系统/浅色/深色）在浅色模式下，选中态应用了灰蒙蒙的 `warm_pill_bg`（`#EFF1F4`），而未选中项反而是纯白的 `surface` 卡片，产生“未选中像被选中浮起、选中反像被按压禁用”的视觉倒错，且未结合主题色系进行自然推导。
3. **顶栏设置图标常亮错误 (图 3)**：顶栏右侧设置按钮判断依据为 `self.settings_window.is_some()`，一旦打开过设置窗口便永久常驻高亮，即便窗口已关闭仍处于激活态，误导用户为双态开关。
4. **顶栏图标线条粗细不均 (图 3)**：当前 16px 工具图标描边统一硬编码为 2.25px，导致密集复杂图标（齿轮设置、软盘保存、展开书籍）视觉面积过大、糊成一团，而线条稀疏图标（代码、下载）相对显得单薄，线条粗细感觉极不协调。
5. **Markdown 点部与列表标记缺乏色彩节奏 (图 3)**：对比图 2（妙言），当前编辑器列表符号（`- `、`* `、`1. `）、任务列表复选框、引用线 `>`、代码块围栏 ` ``` ` 仅为纯单色黑白或普通纯文本，缺乏妙言式的雅致淡彩色呼吸感。
6. **Mermaid 复合连线与类修饰符报错崩溃 (图 3)**：用户在图表中输入复合连线（如 `A & B --> C` 或 `& N2_2 & N2_3 -> N3`）及类修饰符（如 `:::code`）时，`rusty-mermaid` 不支持此类高级简写语法，抛出 `ParseError { kind: UnexpectedToken, span: ... }` 并回退为大块红框错误。

## 决策 (Decisions)

### 1. 设置视窗无缝贯穿左右分栏重构 (Ticket F1)
- **彻底移除 44px 顶部横向标题条**：
  - 去除 `h(px(44.)).border_b_1()` 顶栏容器；
  - 窗口主体采用全高横向 flex 双栏容器：左侧为 160px 导航侧栏，右侧为全高设置内容滚动区。
- **左侧导航栏 Edge-to-Edge 贯穿与红绿灯内嵌**：
  - 窗口左上角预留 36px 顶部安全边距（`pt(px(36.))` 或 `pt(px(40.))`），供 macOS 原生红绿灯直接内嵌展示；
  - 搜索框与各个分类导航项从红绿灯下方平滑排布，左侧边框与底色纵贯到底，完美契合 macOS 现代设置与主 App Drawer 风格。

### 2. 分段控件 macOS 原生质感与色彩系统化推导 (Ticket F2)
- **Segmented Control 结构重塑**：
  - 容器槽底：采用低对比半透明中性底色（浅色：`rgba(0, 0, 0, 0.05)`，深色：`rgba(255, 255, 255, 0.06)`），带圆角与 2px 内边距；
  - 未选中态项：背景完全透明（`transparent_black()`），文字为 `theme.text_muted`，鼠标悬停时微弱提亮；
  - 选中态项：
    - 浅色模式：推导为纯白卡片（`#FFFFFF`），带极微弱浮雕边框或投影，文字为纯净深碳灰（`#1F2328`）或高对比强调色，字体加粗（`MEDIUM`）；
    - 深色模式：推导为亮深石灰卡片（`#343942`），带清晰分界轮廓与高亮文字；
- **全应用 Pill 控件色彩统合**：
  - 规范外观模式切换、自动保存、Tab 大小等所有分段切换卡片，消除生硬的灰白倒错。

### 3. 顶栏设置状态修复与 16px 图标线条粗细归一 (Ticket F3)
- **设置按钮恢复标准 Action 行为**：
  - 将 `btn_settings` 的 `active` 状态从 `self.settings_window.is_some()` 强制修正为 `false`，取消错误常亮，恢复为仅在 Hover 与 MouseDown 触发反馈的标准操作按钮。
- **顶栏 16px 图标线宽与视觉重量均一化**：
  - 对 `assets/icons/` 中的顶栏图标（`code.svg`, `columns-2.svg`, `book-open.svg`, `save.svg`, `download.svg`, `settings.svg`）进行视觉分量平衡微调；
  - 将复杂密集型图标（`settings.svg`, `book-open.svg`, `save.svg`）的 `stroke-width` 从粗笨的 `2.25` 收紧至精致的 `1.5` ~ `1.75`，保持内部镂空清晰；
  - 调整各图标的视口内边距与留白，确保排布在同一顶栏时线宽与视觉黑度完全协调。

### 4. Markdown 点部语义着色与语法标缀节奏感 (Ticket F4)
- **Token 矩阵扩充“点部语义色” (`syntax_bullet`)**：
  - 在 `ThemeColors` 中新增 `syntax_bullet`（或细化 `syntax_marker`）：
    - 妙言默认主题：浅色 `#0969da` (雅致青蓝)，深色 `#58a6ff` (冰川天蓝)；
    - Claude 暖色：浅色 `#d97706` (琥珀暖金)，深色 `#fbbf24`；
    - 其余各调色板严格遵循固有冷暖调推导对应的点缀色。
- **Tokenizer 语法识别拓展**：
  - 列表前缀识别：无序列表标记（`- `, `* `, `+ `）、有序列表前缀（`1. `, `2. `）、任务列表标记（`- [ ]`, `- [x]`）；
  - 标点弱化色彩：标题前缀 `#`、引用前缀 `>` 赋予微弱弱化色彩（`syntax_bullet` 或 `syntax_heading` 弱透明度），正文内容保持纯正碳灰，实现妙言特有的视觉节奏。
- **预览区无序列表与编号同步**：
  - 预览区无序列表的圆点标记由原先纯黑统一为 `theme.syntax_bullet`，与编辑器高亮完美呼应。

### 5. Mermaid 复合语法脱糖展开与容错机制 (Ticket F5)
- **轻量脱糖展开器 (Mermaid Desugarer)**：
  - 在 `crates/glidemark_core/src/mermaid.rs` 的 `sanitize_mermaid` 中增加 AST/行级脱糖：
    - 针对 `A & B --> C` 或 `A --> B & C` 复合语法：平铺展开为标准的多条单边（`A --> C`, `B --> C`）；
    - 针对连线中包含多个前置/后置复合节点（如 `& N2_2 & N2_3 -> N3`）：精准提取所有节点 ID 并展开为原子边；
    - 清理/脱敏类修饰符缀词（如 `:::code`, `:::llm`），避免 `rusty-mermaid` 词法解析器抛出 `UnexpectedToken`；
- **解析健壮性保障**：
  - 无论语法树输入何种变体，预处理后均能被 `rusty-mermaid` 稳定转为无畸变 SVG，杜绝界面大面积报错红框。

## 验证策略
1. **自动化测试**：
   - 为设置视窗左右分栏、Segmented Control 样式、设置按钮 active 状态、Markdown 列表 tokenizer、Mermaid `&` 展开分别编写独立单元测试；
   - 保证全量 `cargo test --workspace` 绿灯且用例数正向递增。
2. **视觉与构建验证**：
   - `./scripts/bundle_macos.sh` 打包生成最新 app；
   - 启动测试，验证设置窗口无横条贯穿分栏、分段按钮质感、顶栏设置按钮正常熄灭、Mermaid 图表无红框崩溃。
