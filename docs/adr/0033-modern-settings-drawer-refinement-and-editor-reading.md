# ADR 0033: 现代化设置视窗、侧栏层级降噪、灯箱纸张画布与沉浸阅读排版

## 状态
提议 (Proposed) - 等待 Ticket D1、D2、D3 分步实施验收后转为 Accepted

## 上下文 (Context)
在 Phase C（视觉精进与 HiDPI 灯箱重采样）落地后，针对用户实际使用中的 4 处核心视觉与交互反馈进行了深度审视：
1. **流程图灯箱半透明底色发脏 (Image 0)**：当前灯箱采用 `rgba(0,0,0,0.45)` 浅暗蒙版，底层正文文字直接透过图表透射出来；且 Mermaid 图表无实体底色，半透明节点与深色背景及穿透文字多重叠加，产生脏污视觉。
2. **设置窗口设计语言断代脱节 (Image 1)**：设置窗口仍沿用早期的固定厚重边框（`border_1`）、高饱和度橙色标题框与传统分段按键，与主工作区已落地的无框暖石微胶囊（`warm_pill`）现代极简风格割裂。
3. **侧栏层级噪音、微型字体与无意义灰点 (Image 2)**：
   - 侧栏顶部常驻“工作区”分组标签，增加了无意义的视觉层级；
   - 树状列表在非活跃打开文档前强制渲染灰色实心小圆点（`·`），在无 Tab 架构下产生“未读/未保存/脏数据”的视觉困惑；
   - 侧栏字体仅 12px，与画布正文对比过小且拥挤。
4. **编辑器排版与交互体验痛点 (Image 3)**：
   - 侧栏条目 Hover 采用纯白 `#FFFFFF`，在暖石底色上对比刺眼突兀；
   - 顶部文档标题位置与下方编辑器代码文本未垂直对齐；
   - 编辑器行高 1.5x 视觉局促，缺乏舒适阅读呼吸感（期望 1.3~1.7x）；
   - 编辑器缺乏基础的 Markdown 语法高亮与自适应软折行（Soft Wrap）。

## 决策 (Decisions)

### 1. 灯箱纸张画布与高纯度遮罩隔离 (Ticket D1)
- **纸张画布 (Paper Canvas)**：在 `lightbox.rs` 中的图表渲染容器内衬注入实体底色（浅色模式采用极简白纸/暖石面板，深色模式采用深石色），添加轻量圆角与柔和漫反射阴影。
- **纯净背景遮罩**：背景遮罩提升为高纯度深色蒙版（`rgba(0, 0, 0, 0.88)`），彻底阻断底层正文透光与视觉杂讯。

### 2. 侧栏层级平铺、无意义灰点清除与字体升级 (Ticket D1)
- **剔除“工作区”标签**：移除抽屉顶部的“工作区”大标题，多根 Roots 文件夹直接顶层平铺罗列。
- **消灭无意义灰点**：彻底移除 `is_open && !is_active` 下渲染的 5px 灰色实心圆点。
- **字体与行距层级提升**：
  - 侧栏节点字号从 12px 提升至 13px，行高增至 28px，增加舒适行内边距；
  - 文件夹与根目录字体略微加重，建立清晰视觉节奏。
- **Hover 态柔化**：摒弃 `#FFFFFF` 纯白高光，采用轻透暖石微胶囊浅色半透高亮（`warm_pill_hover`）。

### 3. 设置窗口现代无框重构与组件复用 (Ticket D2)
- **左侧导航**：全面迁移为与 Drawer/Header 一致的 `warm_pill` 微胶囊结构，去除外边框，选中态采用暖石微胶囊高亮。
- **外观模式与排版**：三态模式切换由厚框按钮重构为无框平铺胶囊；调色板列表引入圆形色样（Color Swatch）与轻透卡片。
- **扩展偏好项**：在偏好设置中增加编辑器行高调节（支持 1.3x ~ 1.7x，步进 0.1x，默认 1.6x）。

### 4. 编辑器视觉对齐、行高调节与语法高亮 (Ticket D3)
- **标题槽位像素对齐**：对齐顶部文档大标题与编辑器第一列代码文本起始位置（避让行号槽位 48px）。
- **可调节舒适行高**：编辑器默认行高提升为 1.6x，由偏好设置动态驱动。
- **轻量纯 Rust Markdown 语法分词着色**：对标题（H1~H6）、行内代码（`code`）、加粗、链接、引用块进行单行轻量正则分词着色，零重型外部依赖。
- **自适应软折行 (Soft Wrap)**：探索支持长行视窗内软折行与光标精准命中。

## 任务拆解与推进节奏

- **Ticket D1 (侧栏降噪、排版升级与灯箱纸张画布)**：
  - 范围：`lightbox.rs`, `drawer.rs`, `theme.rs`
  - 独立测试套件：`drawer_polish_test.rs`, `lightbox_paper_canvas_test.rs`
- **Ticket D2 (设置窗口全量无框现代化重构)**：
  - 范围：`settings.rs`, `config.rs`, `state.rs`
  - 独立测试套件：`settings_modern_ui_test.rs`
- **Ticket D3 (编辑器视觉对齐、1.6x 行高与 Markdown 语法高亮)**：
  - 范围：`editor.rs`, `workspace.rs`, `editor_engine/`
  - 独立测试套件：`editor_reading_enhancement_test.rs`

## 后果与影响 (Consequences)
- **正面收益**：
  - 灯箱图表阅读体验大幅飞跃，彻底告别文字穿透与杂色干扰；
  - 侧栏纯净度提升，无多余层级与噪音小圆点，字号舒适护眼；
  - 设置窗口与主界面设计语言实现 100% 统一，消除视觉割裂；
  - 编辑器正式具备现代化阅读与代码着色体验。
- **架构约束与兼容**：
  - 语法分词在单行渲染内轻量进行，严格遵守单帧微秒级预算，杜绝复杂文档掉帧；
  - 严格保持偏好设置向前兼容，新增配置字段缺失时优雅回退至默认值。
