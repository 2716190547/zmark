# ADR 0013: 解耦独立分栏设置窗口、双向平滑抽屉动画、三级色彩层级与全画幅纯白 Dock 图标

## 状态
已接受 (Accepted)

## 上下文 (Context)
1. **Dock 栏图标“一层套一层”视觉缺陷**:
   - 上一版在 1024x1024 画布中心绘制带有 100px 透明边距的 824x824 白色圆角矩形，当 macOS Tahoe Dock 渲染时，系统在自身的毛玻璃托盘底座（第一层）内，再次套嵌了该白色小矩形（第二层），视觉上造成“套娃方框”感。
2. **界面各区块缺乏微弱颜色区分**:
   - 此前抽屉、编辑器主体与预览区均为统一的 `#FFFFFF` 平铺白底，导致整个窗口缺少结构支柱与视觉锚点，层次感微弱。
3. **侧边栏关闭时缺失平移动画**:
   - 此前展开侧边栏时使用了 `with_animation("drawer_slide_in")`，但收起时直接使用 `.when(drawer_open)` 条件卸载，导致抽屉在 0ms 瞬间闪断消失。
4. **用户明确偏好独立分栏设置窗口**:
   - 用户明确要求保留独立弹窗与左右分栏的设置体验（类似系统偏好设置与原生桌面工具），拒绝嵌入式侧抽屉方案。

## 决策 (Decision)
1. **全画幅铺满纯白 Dock 图标 (Full-Bleed Pure White 1024x1024)**:
   - 彻底移除图标脚本中的四周透明安全边距，将 1024x1024 画布整张铺满纯白底色（`#FFFFFF`），中心居中 620x620 暖色红褐至金黄琥珀渐变 Z 标志。
   - 当 macOS Dock 加载图标时，由系统自带的统一标准单层 Squircle 蒙版完成圆角裁剪，与 Dock 原生托盘严丝合缝融为一体，彻底消灭内部嵌套小卡片。
2. **经典 3 级微色调阶梯 (3-Tier Tonal Hierarchy)**:
   - **第 1 级（窗口控制台与侧边栏）**：微浅雾灰底色（`theme.bg = #F0F0F4`），涵盖顶栏与左侧目录/大纲抽屉，形成沉稳内敛的控制框架。
   - **第 2 级（窗格顶部状态栏）**：源码编辑器与预览区顶部的信息栏（行号/块数/状态）统一采用 `theme.bg` 底色与 1px 微发丝底边（`theme.border = #E2E2E8`），为两栏提供整齐的视觉顶部横梁。
   - **第 3 级（核心书写与阅读区）**：采用纯净纸张白（`theme.surface = #FFFFFF`），搭配两栏之间 1px 细线与 5px 悬停高亮拖拽调节区，层次分明、呼吸自然。
3. **双向 180ms ease-in-out 平滑动效 (Bidirectional Drawer Animation)**:
   - 在工作区维护 `drawer_closing` 状态。
   - 展开时：`180ms` 从 `0px` 平滑过渡至 `250px`；
   - 收起时：先激活 `drawer_closing`，执行 `drawer_slide_out` 动效（从 `250px` 平滑回缩至 `0px`），并在 180ms 定时器完成后优雅卸载。
4. **解耦异步独立分栏设置窗口 (`SettingsWindowView`)**:
   - **彻底杜绝闪退**：通过 `cx.defer` 异步派发窗口创建指令，避开事件监听堆栈上的 `&mut WorkspaceView` 借用；`SettingsWindowView` 拥有独立的状态拷贝与 `WeakEntity<WorkspaceView>`，在自身的 `render()` 中绝不读取主工作区，彻底消除 Rust 借用竞争。
   - **两栏排版布局**：
     - 左侧导航栏（160px，`theme.bg`）：外观、编辑器与保存、语言、关于四大模块胶囊导航；
     - 右侧内容区（flex-1，`theme.surface`）：独立滚动容器，包含模式切换、8 套调色板、自动保存微调、10 国语言切换及快捷键概览；
     - 顶部预留 80px macOS 红黄绿交通灯安全区，拥有专属窗口生命周期与快捷键唤起。

## 结果 (Consequences)
- Dock 栏图标彻底消灭“一层套一层”问题，在浅色与深色桌面上均呈现单一、饱满、纯净的白底暖金图标。
- 窗口层级清晰分明，控制栏与纸张书写区视觉反差和谐，兼顾现代感与专注力。
- 侧边栏展开与收起均具备流畅平滑的 60fps 动效，告别生硬突兀感。
- 原生独立分栏设置窗口运行稳定，支持 `⌘,` 随时呼出与激活，所有 30 项测试全部通过。
