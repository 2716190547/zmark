# ADR 0037：真实文字布局、虚拟化预览选区与侧栏文件名搜索

状态：Accepted，2026-11-03。代码 `1f68fa3` 独立终验通过，P1:0；交付范围和遗留问题见 [Phase H 验收](../plans/phase-h-delivery.md)。

GPUI 的文字绘制不自动具备系统文本选取和输入能力；先前按字符单元估算的折行、按键拼接搜索及整块选区，无法保证中文输入、命中和复制一致。保留原生 GPUI、编辑缓冲区和预览虚拟化，通过实际字形度量、可见文字区域与文档字符范围映射接通交互；不为获得浏览器式选取而引入 WebView，也不通过取消虚拟化渲染整篇文档。

## 决策与取舍

- 源码绘制、点击、光标、上下导航及双向同步滚动使用同一份真实折行结果。普通编辑复用未变物理行的度量和折行，避免每次 revision 变化都在 UI 线程重新 shape 全文；宽度和字号变化仍需正确失效。
- 预览仅登记当前绘制文字区域，按视图持有并在每帧更新。区域保存实际容器位置及该文字的字号、字体、行高和文档字符范围；命中、嵌套高亮及纯文本复制保持同一范围语义。选区状态独立于可见虚拟行，自动滚动推进可见内容和选区，焦点路由决定复制权。
- 搜索文本由 GPUI 系统输入处理器单一负责，支持组合输入与基本编辑；不同时在 Workspace 的 KeyDown 回调中手工追加文本。搜索为文件名搜索，过滤目录树并保留原展开状态，未载入目录在后台按预算扫描；不增加全文索引。
- 生产事件回归可通过 `test-observation` feature 获取真实渲染位置和高亮范围。观测代码不参与正常打包，业务修复不依赖该 feature；关键检查以真实事件和隔离回退失败证明判别力，不能仅测试序列化或源码字符串。

## 对 ADR 0036 的局部替代

- 默认与 Claude Warm 的选中背景略偏暖；其他调色板保持原色调，统一经既有语义方法供组件使用，悬停与明暗适配保留。
- Source／Split 标题对齐源码文字起点，Preview 标题对齐居中正文版心；去掉固定 320px 限制，保留工具栏及红绿灯安全区。
- 侧栏搜索推迟项已实施，设置页搜索继续删除；两种搜索不是同一功能。

## 边界

本次采用的区域度量与输入方案保持轻量，但不是完整的系统富文本控件。自动滚动字符级命中仍有估算分支、顶部停止和真机失活及时性等限制；换行密集文档连续改宽仍可能全量重排，后台搜索也有取消、异常复位及深度提示缺口。审查将它们列为 P2，不能据本 ADR 声称这些问题已解决，完整清单见验收记录。
