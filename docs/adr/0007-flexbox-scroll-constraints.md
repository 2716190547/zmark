# ADR 0007: Flexbox 滚动约束与布局根因修复

## 状态
已接受 (Accepted) - （注：早期探索的视觉主题与图标决策已分别由 ADR 0021、ADR 0015 最终确立）

## 上下文 (Context)
在实际测试中发现两大严重破坏阅读与编写的核心布局 Bug：
1. **正文无法纵向滚动 (Scroll Max = 0)**：在阅读模式或源码模式下，长文档无法使用滚轮或触控板向下滚动，页面固定在顶部。
2. **分屏模式右侧预览消失 (Split Column Blowout)**：切换到左右分屏模式时，左侧源码列如果包含长文本行，直接将右侧预览列挤出可视窗口边界。

## 决策 (Decision)
1. **Flexbox 最小高度约束（根治滚轮失效）**:
   - 在 CSS Flexbox 及 GPUI 底层的 Taffy 弹性盒引擎中，带有 `flex_1()` 的子容器默认 `min-height: auto` (`min-content`)。
   - 当包含长文档内容时，容器自动延展为内容的内在总高（如 5000px），导致外层视口计算的可滚动溢出高度恒为 0（`scroll_max = 0`），滚轮事件无法产生有效位移。
   - **工程修复**：在各级内容容器上显式声明 `.min_h(px(0.))`，强行允许容器在父视口内按需收缩，彻底解锁流畅的 GPU 高刷滚动。
2. **Flexbox 最小宽度与裁剪约束（根治分屏挤压）**:
   - 在分屏模式下，左侧源码行由于长文本无限向右延展，在未加约束时弹性列宽度自动膨胀。
   - **工程修复**：在分屏的两侧容器上显式配置 `.min_w(px(0.)).overflow_hidden()` 与相对百分比宽度约束，确保左右两栏严格遵循分屏比例并支持各自独立滚动。

## 结果 (Consequences)
- 彻底根除了 GPUI / Taffy 架构下的纵向滚动卡死与分屏挤出视口 Bug，该布局约束成为全工程容器的标准设计规范。
