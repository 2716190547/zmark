# ADR 0010: macOS 全画幅图标去套娃、原生极简分段选择器、防抖自动保存与分栏设置重构

## 状态
已接受 (Accepted)

## 上下文 (Context)
1. **macOS Dock 图标套娃**: 
   - 之前 `generate_icon.py` 在 1024x1024 画布上手动绘制了 864 尺寸的圆角矩形，留出 80px 透明外边距。
   - macOS 27 系统 Dock 栏具有自动毛玻璃托盘机制，检测到透明边缘后自动套上了系统 squircle 底座，导致内层白色卡片与外层系统底座形成「双层套娃（Squircle Jail）」。
2. **视图模式切换器选中视觉生硬**:
   - 之前视图模式切换器（源码/分屏/预览）选中时直接使用 `bg(theme.surface).shadow_sm()`，在浅色界面下产生突兀的灰黑模糊阴影和块状浮起感，破坏了扁平整洁度。
3. **缺少自动保存**:
   - 依赖快捷键 ⌘S 或失焦保存容易导致输入中断或内容意外丢失，需支持静默且防抖的自动保存机制。
4. **设置界面拥挤单列排版**:
   - 随着主题、多语言、自动保存、Tab 大小等配置项不断增多，单列纵向弹窗信息密度失衡，需要结构清晰的分栏排版。

## 决策 (Decision)
1. **Full-Bleed 1024 全画幅 Dock 图标**:
   - 移除 `generate_icon.py` 中 80px 的透明留白，白底直接全画幅 1024x1024 铺满，让暖红褐-暖黄渐变的 Z 造型居中排版。
   - 由 macOS LaunchServices / Dock 唯一原生裁切标准圆角，彻底消除双层嵌套。
2. **纯粹 macOS 同心分段胶囊控制（Segmented Control）**:
   - 外层容器使用 `rounded(px(7.))`、内边距 `p(px(2.))`、弱描边 `border_1().border_color(theme.border)` 与微浅背景。
   - 选中胶囊项使用 `rounded(px(5.))`（7 - 2 = 5 同心半径）、微线框贴合，彻底移除 `shadow_sm()` 阴影，与浅色/深色主题自然无缝贴合。
3. **零依赖任务驱动的防抖自动保存**:
   - `Preferences` 新增 `auto_save: bool`（默认 `true`）与 `auto_save_delay_ms: u64`（默认 `1000`）。
   - 在 `WorkspaceView` 中利用 GPUI 异步生命周期 `Task` 的赋值自动 Cancel 语义，键入修改后触发 1000ms 定时器防抖静默保存，窗口失焦/关闭时确保即时落盘。
4. **分栏两列设置面板**:
   - 左侧导航栏（160px）：外观与主题（`icons/palette.svg`）、编辑与保存（`icons/save.svg`）、界面语言（`icons/languages.svg`）、关于（`icons/info.svg`）。
   - 右侧内容区：支持各个分类下的独立卡片与即时响应配置，所有 10 种语言均已完整本地化。

## 结果 (Consequences)
- Dock 栏图标呈现与系统原生 App 完全一致的单层极致圆角。
- 顶部栏模式切换器呈现高度精致的 macOS 原生质感。
- 用户输入即受 1 秒防抖自动保存保护，无丢字风险。
- 设置界面模块分明，可扩展性极佳。
- 全套 30 个单元与集成测试全部通过。
