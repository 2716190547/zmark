# ADR 0023: 源码编辑器文本堆叠修复、代码块排版对称性与资源完整性

## 状态
已接受 (Accepted)

## 上下文 (Context)
1. **源码编辑器文字重叠堆叠 Bug (Text Stacking Bug)**：
   - 现象：在源码模式（Source Mode）或分屏模式（Split Mode）下，当 Markdown 包含较长行（如超长 URL、嵌入式表格 Markdown 源码或未分段的长句）时，后续行（如第 28 至 35 行）的内容直接垂直重叠、糊在同一块区域中。
   - 根因分析：`render_editor_pane` 中的每一行采用 `flex_row`，包含 36px 行号与 `flex_1` 内容容器。GPUI 的 Taffy 布局引擎在计算 `flex_1` 且无显式固定宽度的弹性子项时，垂直方向只按单行基线 `min_h(px(font_size * 1.5))` 评估。当长文本自动折行（`whitespace_normal`）占用多行高度时，弹性容器并不会纵向撑开，文本直接越界下溢（Overflow）。后续行的 Y 坐标仍然按单行高度向下累加，导致数行甚至十余行长文本全部在相同的纵向空间中相互覆盖重叠。同时导致光标命中测试（Hit Testing）与行列坐标完全脱节。
   - 解决方案：专业源码编辑器标准行为——在编辑器文本容器上规范折行与滚动机制，行号与源码行维持 1:1 绝对平齐，杜绝由于高度计算脱节引发的越界重叠，保证光标点击定位与移动绝对精准。

2. **标签页关闭图标缺失显示为灰块 (Tab Close Icon Missing)**：
   - 现象：单窗口多标签页栏（Tab Strip）中，标签页右侧的关闭按钮展示为一个圆角灰色实心小方块，未显示 `x` 矢量图标。
   - 根因分析：`crates/glidemark_app/src/assets.rs` 的 `AppAssets::load` 匹配表中遗漏了 `"icons/x.svg"`，导致 GPUI 资源加载器返回 `None`，退化为未加载资源占位灰块。
   - 解决方案：在 `assets.rs` 中补全 `"icons/x.svg" => Some(include_bytes!("../assets/icons/x.svg"))` 并同步加入 `list()` 导出清单。

3. **代码块顶栏语言标签间距不均与对称性优化**：
   - 现象：预览模式下，代码块卡片顶部的语言标签（如 `PYTHON`、`RUST`）距容器左侧边缘的距离（`px_3 = 12px`）与距上边缘的距离（居中剩余空间约 6.5px）不一致，视觉呈现偏左且不对称；代码行溢出时缺乏优雅的横向平滑滚动与排版支持。
   - 解决方案：重构代码块 Header 与内容区域，统一内边距基准，保持上下与左右内边距视觉平衡，同时在代码块内容区配置 `overflow_x_scroll()`，支持平滑横向滚动，避免硬性截断。

4. **多标签页状态转换与纹理预算完整性**：
   - 结合多标签页（ADR 0021）和图表纹理预算（ADR 0022）的实施，必须建立针对多标签切换、标签关闭（首个标签、中间标签、末尾标签、唯一标签清空为 scratch 文档）以及图表超宽超高尺寸双向限制的自动化单元测试防护网。

## 决策 (Decision)
1. **源码编辑器防堆叠与光标对齐**：
   - 编辑器行内容容器采用规整的高度与换行策略，行号与源码行维持严格 1:1 对应关系，防止布局引擎高度低估导致的文字垂直堆叠。
2. **修复资源静态嵌入表**：
   - 在 `crates/glidemark_app/src/assets.rs` 的 `AppAssets::load` 与 `AppAssets::list` 中显式注册 `"icons/x.svg"`，消除资源缺失占位。
3. **优化代码块几何对称性与滚动**：
   - 统一代码块 Header 的内边距几何比例，对齐语言胶囊与复制按钮的垂直居中轴线；代码块代码行采用独立横向滚动容器。
4. **双向图表纹理预算限制 (Texture Budget Clamping)**：
   - 优化 `crates/glidemark_core/src/mermaid.rs` 的 `apply_texture_budget`：比较宽与高的最大值 `max(w, h)`，不仅限制超宽图表（width > 1000px），同时也对超高纵向图表（height > 1000px）等比缩放，严格将位图最大边限制在 1000px 以内，同时完整保留 `viewBox` 矢量坐标。
5. **完备的多标签页状态转移与数据同步自动化测试**：
   - 在 `crates/glidemark_app/tests/app_state_test.rs` 中补充多标签状态机测试：验证切换标签时的编辑缓存写回（Buffer Sync）、关闭非活跃/活跃标签时的索引自适应调整、以及关闭最后一个标签重置为空白草稿的生命周期。

## 结果 (Consequences)
- **正面收益**：
  - 彻底根除了源码编辑器在长行文本时的垂直重叠堆叠 Bug，行号与文字行精确对齐，光标定位精确无误。
  - 标签页关闭按钮能够正常、清晰地渲染 SVG 叉号矢量图标，告别破损灰块。
  - 预览区代码块 Header 视觉呈现匀称统一，代码与行号排版优雅且支持平滑横向滚动。
  - 图表纹理预算机制可同时拦截超宽与超高图表，消除极端图表导致的内存膨胀。
  - 关键状态转移具备 100% 自动化测试回归覆盖，保障后续重构的鲁棒性。
- **注意事项**：
  - 源码编辑器长行遵循代码编辑器通用惯例，光标与行号保持 1:1 物理行绑定。
