# ADR 0011: 原生独立设置窗口、悬浮圆角工作卡片分层与透明矢量 Dock 图标

## 状态
已接受 (Accepted)

## 上下文 (Context)
1. **设置弹窗为内联遮罩模态**:
   - 此前设置面板为工作区内部的 `.absolute().inset_0()` 覆盖模态，遮挡正文编辑且不符合标准 macOS 桌面应用的独立窗口规范。
2. **工作区各个区块扁平缺乏层级**:
   - 抽屉栏、源码编辑区与阅读预览区此前均为纯白平面堆叠（`#FFFFFF` 对 `#FFFFFF`），仅靠 1px 微发丝分割，在视觉上缺乏空间纵深与清晰的区块认知。
3. **macOS 27 Dock 图标边缘露出灰色底座**:
   - 在 macOS 27 Tahoe 的统一毛玻璃托盘机制下，包含外层白底方块的图标会被系统微幅缩放并居中嵌套在 67px 玻璃砖内，导致四周露出约 5px 灰色毛玻璃空隙。

## 决策 (Decision)
1. **独立 macOS 原生设置窗口 (`SettingsWindowView`)**:
   - 按 `⌘,`、点击顶部控制台设置齿轮或通过菜单调出时，通过 GPUI `cx.open_window` 打开原生专属独立设置窗口（640x460 居中）。
   - 具有独立的 macOS 红黄绿交通灯、窗口标题与生命周期，关闭设置窗口不打扰主窗口。
   - 通过 `Entity<WorkspaceView>` 实现跨窗口即时双向同步：在设置窗口切换主题、调色板、语言、自动保存时，主编辑器窗口毫秒级响应并即时重绘。
2. **悬浮圆角工作卡片架构 (Elevated Rounded Cards)**:
   - 窗口底板（Canvas）采用温润克制的微浅雾灰（`theme.bg = #F4F4F6`，暗色为 `#131315`）。
   - 主工作区施加全局安全呼吸边距（`.px(px(8.)).pb(px(8.)).gap(px(8.))`）。
   - 目录抽屉、源码编辑器与阅读预览区分别重塑为**独立的实体工作卡片**（`bg(theme.surface = #FFFFFF)`、`rounded_xl` 12px 圆角、`border_1()` 微发丝边线、`overflow_hidden()`），区块分层一目了然。
   - 分屏调节条重构为两张浮动卡片之间 8px 呼吸间距内的同心胶囊手柄（`rounded_full()`），带来极致的现代 macOS / MiaoYan / Linear 质感。
3. **纯透明背景矢量 Z 造型图标 (Transparent Glyph)**:
   - 移除 `generate_icon.py` 中一切多余的白色矩形衬底，输出 1024x1024 纯透明背景与暖红褐至暖金琥珀渐变的纯净矢量 Z 轮廓。
   - 当 macOS 27 将图标安放于 Dock 栏时，直接以系统原生玻璃砖作为唯一承载托盘，完全杜绝白底缩放外露灰色底座的问题。

## 结果 (Consequences)
- 设置成为标准的独立多窗口应用架构，交互完全符合 macOS 习惯。
- 界面由原来的平铺白底升级为空间层级分明、触感立体的圆角工作卡片，可读性与美感极大提升。
- Dock 栏图标完美自然贴合系统玻璃底座，无任何嵌套毛边。
- 工作区 30 个单元与集成测试全部无缝通过。
