# ADR 0016: 响应式宽幅排版、Mermaid 拓扑连线与多形状支持、图标字重微调及主题自动跟随模式修复

## 状态
已接受 (Accepted)

## 上下文 (Context)
在多轮实际使用与视力测试中，用户反馈了以下 4 项关键视觉与交互缺陷：
1. **内容未响应式撑满宽度与右侧截断**：
   - 预览区此前硬编码了 `820px` 最大列宽（`max_column_width`），导致在宽屏窗口或分屏状态下内容偏窄，且长中文段落与宽表格在右侧被强制裁切截断。
2. **Mermaid 图表缺失连线、形状与条件分支文本**：
   - 流程图仅渲染了扁平卡片列表，缺失了级联连线、方向指示器以及边文本（如 `-->|Yes|`、`-->|No|`）；节点形状亦全部降级为通用矩形，无法区分判断菱形 `{}`、数据库柱形 `[()]` 或圆角胶囊 `()`。
3. **页面功能图标过小且线条偏细**：
   - 顶栏、侧边栏及模式切换器的图标尺寸偏小（16px）且矢量描边仅为 2.0pt，相较于设计标杆（妙言 MiaoYan）视觉比重偏弱，触控目标不够鲜明。
4. **切换主题调色盘时误触发暗色模式**：
   - 当外观设置为“跟随系统”（`ThemeMode::Auto`）且系统处于浅色模式时，在设置界面点击不同的色彩调色盘，会导致应用瞬间强制切换为深色模式。

## 决策 (Decision)
1. **全面实现自适应全宽响应式排版 (Fluid Responsive Layout)**：
   - **预览容器**：移除固定 820px 宽度上限与外边距居中约束，容器全面采用 `.w_full()` 扩展。
   - **表格与段落**：表格外部容器包裹独立滚动层 `.id("preview_table_scroll").w_full().overflow_x_scroll()`，内部表格赋予 `.min_w(px(520.))` 底线，表头与单元格设定 `.min_w(px(120.))` 与 `.flex_wrap()`，彻底根除文字截断。
   - **编辑器行内排版**：行容器对齐方式由居中改为顶部对齐（`.items_start()`），行号保持固定宽度（`.w(px(36.)).flex_shrink_0()`），文本容器增加 `.min_w(px(0.))` 与 `.flex_wrap()`。
2. **Mermaid 语法解析器与 GPU 拓扑渲染升级**：
   - **核心解析器 (`glidemark_core::mermaid`)**：
     - 支持无引号扩展形状解析（`{Diamond}`、`[(Database)]`、`(Rounded)`、`[Rectangle]`）；
     - 支持内联分支条件标签提取（`-->|label|`、`-- label -->`）。
   - **视图拓扑渲染 (`preview.rs`)**：
     - 在阶段卡片之间引入显式级联垂直导轨与方向指示器（`▼`）；
     - 渲染条件徽标（如 `[Yes] ▼`），清晰表达分支语义；
     - 针对四种节点形状分别赋予专属几何描边：菱形判断节点（`rounded_2xl().border_2()`）、数据库（`rounded_t_2xl().border_t_4()`）、圆角胶囊（`rounded_full().px_5()`）与标准圆角矩形。
3. **对齐妙言 (MiaoYan) 的高辨识度图标视觉规格**：
   - 全局更新 `crates/glidemark_app/assets/icons/` 全部 17 个 SVG 图标描边字重，由 `stroke-width="2"` 提升至 `stroke-width="2.25"`；
   - 顶栏主要功能图标尺寸提升至 `20px`，触控响应胶囊提升至 `32x32px`；
   - 抽屉侧栏标签图标提升至 `16px`；
   - 视图模式分段选择器图标提升至 `18px`，按钮尺寸调优为 `36x26px`。
4. **修复主题调色盘与外观模式的状态解耦**：
   - 根因分析：`AppState::recompute_theme()` 中此前错误地将 `ThemeMode::Auto` 与 `ThemeMode::Dark` 一并归为深色（`ThemeMode::Dark | ThemeMode::Auto => true`）。
   - 架构修复：在 `AppState` 中引入真实系统外观标识 `is_system_dark: bool`；在 `recompute_theme()` 中明确计算 `ThemeMode::Auto => self.is_system_dark`；并在测试套件中加入“跟随系统浅色模式下切换色彩保持浅色”的回归断言。

## 结果 (Consequences)
- 在任意窗口比例下，文章与表格均能自然撑满并支持横向平滑滚动，无右侧字符吞没现象。
- Mermaid 流程图具备完整的图拓扑连线与语义形状表达。
- 界面图标轮廓更为清晰饱满，与 macOS 原生应用质感完全对齐。
- 主题切换与系统深浅色外观实现严密解耦，无异常闪烁或错位。
