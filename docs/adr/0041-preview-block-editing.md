# ADR 0041：预览按块编辑

状态：Accepted，2026-11-28。来源：GitHub issue #30。

## 背景

issue #30 要求在预览里直接改文字。完整所见即所得要把渲染树和源码双向绑定，改动面过大。每个顶层块已有 `SourceAnchor`（起止源码行），全局只有一个 `EditorEngine`，所以可以让一个块临时换成源码编辑框。

## 决策

1. **默认关闭**。`Preferences.preview_inline_edit` 默认 `false`，开关在设置「编辑器与保存」分组。关闭时预览只读，与 0.2.15 一致。
2. **单击进入，拖动仍是划词**。按下记下块号、字符偏移和位置；松开时位移小于 4px 且选区未展开才打开该块。链接、图片、复选框和代码块复制按钮在按下时阻止冒泡，不会触发编辑。
3. **可编辑块**：段落、标题、分隔线、列表、引用、表格。列表和引用取最外层顶层块，表格整表一块。代码块、Mermaid、`[toc]` 和 `<br>` 间隔不可编辑；开关开启时双击代码块切到分屏，光标落在代码首行。
4. **编辑框是源码编辑器的另一个视图**。编辑框直接改共享 `EditorEngine`，撤销、脏状态、自动保存和分屏源码侧同步。按键、粘贴、IME 走源码编辑器的 `EntityInputHandler`；编辑框只有自己的行几何（`block_rows`，命中测试与 IME 候选框定位用它代替 `source_rows`）和按预览版心宽度的折行（`block_visual`）。分屏时源码侧在编辑框打开期间不注册输入处理器。
5. **范围由尾部行数确定**。记录起始行、起始字符偏移和块后剩余行数；输入只发生在框内，所以末行 = 总行数 − 1 − 尾部行数。框首退格、框尾删除被忽略，不与相邻块合并；全选只选框内。撤销重做若改到框之前的文本，关闭编辑框并立即解析。
6. **编辑期间不重新解析**，块索引不漂移，组字也不会触发解析。按 Esc、点击框外、光标移出框（方向键越过首末行）、切到源码模式时退出并解析一次；点击另一个块时先退出，再按块数变化平移命中的块号。手动保存和导出会解析，之后按源码行重新定位编辑框覆盖的块。切换或重载文档时丢弃编辑框（改动已在缓冲区）。
7. **高度与滚动**。编辑框作为该块由同帧测量（ADR 0039）测得真实高度；顶部锚点规则保证框在视口顶部时其上内容不动。
8. **光标定位**。点击处的渲染文本偏移按顺序匹配到源码字符（跳过标记符号），匹配不到时落在已匹配位置之后。
9. **打开和关闭有过渡**。块的总高度在 220ms 内按 `ease_out_quint` 从原高度变到新高度：`MeasuredBlocks` 先按自然高度排版该组块，再裁剪到当前插值高度，并把插值高度报给高度表，下面的块随之平移，屏幕其他部分不动。打开时渲染块淡出、编辑框淡入（编辑框在上层，过渡中双击仍落在编辑框）；关闭时重新渲染的块从 20% 不透明度淡入。点另一个块时关闭和打开两段过渡同时进行。开启「减少动态效果」时直接切换。编辑框的折行和字符位置按块文本、版心宽度和字号缓存，过渡帧不重新排版。

## 结果

- 只读预览的用户不受影响；编辑路径不新增文本存储或撤销栈。
- 已知限制：编辑框用等宽源码字体，不保留渲染样式；光标映射对 HTML 实体、转义字符和自动编号可能偏几个字符；编辑框内拖动选区不触发自动滚动；中键列选在编辑框内不可用。
